Э-3 · Поиск тренера город/зал + специализации
Точки входа: инфо-кнопка в «Технике» (#52), Профиль → «Найти тренера», бот /trainer. Один input «Город или зал» (вхождение текста, без карт), чипы специализаций (совпадение по любой). В результатах — только подтверждённые карточки. Пустые состояния: «Ничего не нашлось + Сбросить» и «Пока нет подтверждённых тренеров».

Э-4 · Карточка тренера + модалка заявки «Стать подопечным»
Публичный вид: био, чипы, зал/город, расписание, стаж, достижения, образование. Контакта в публичной карточке нет (вопрос №5). Э-8 · Групповые занятия — концепт светлая тема · вне итерации S1
