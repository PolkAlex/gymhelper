# Заметки проекта (проверять в начале работы)

## 🛟 Восстановление случайно удалённой тренировки (с 02.11.2026)
Сервер хранит 20 последних версий файла каждого пользователя: `/opt/gym/data/backups/chat_<id>.<timestamp>.json`.
Бэкап создаётся ПЕРЕД каждой перезаписью, то есть версия с удалённой тренировкой есть почти всегда.
Процедура восстановления (делает владелец сервера/ассистент):
1. `ssh root@45.91.169.125` → `ls -t /opt/gym/data/backups/chat_<id>.*.json | head -5`
2. Найти бэкап, где нужная тренировка ещё есть: `python3 -m json.tool <файл> | less` (искать дату).
3. Скопировать найденный workout-объект в живой файл `/opt/gym/data/chat_<id>.json` (id тренировки должен быть < nextId!) и перезапустить: `systemctl restart gymbot`. Либо просто положить бэкап на место живого файла, если пользователь не менял данные после удаления.
ВНИМАНИЕ: если id удалённой тренировки попал в `del` (tombstones) — при восстановлении убрать id из `del`, иначе сервер снова её удалит.
