5 · Частичный ввод ошибка сохранения · [I8-update]
Год 1985 выбран, месяц «—» → тост «Укажи и год, и месяц…», оба select с рамкой --danger. Выход за диапазон невозможен: список годов содержит только допустимые (2021…1930 = возраст 5–96 лет); защитная проверка 5–100 остаётся на сервере и в боте. Сохранение заблокировано, дата из профиля не тронута.

6 · Бот: ввод года одной строкой + клавиатура месяцев сценарий
Формат строки прежний «пол X рост вес»: X 5–100 = возраст (как раньше; [I8-update 09.11] минимум 5 вместо 10), X 1930–2021 = год рождения (диапазоны не пересекаются: 100 < 1930; год с возрастом < 5 — ошибка диапазона). После год-ввода бот просит месяц кнопками (callback bm:1…bm:12); сохранение — только после выбора месяца. «🏠 Меню» отменяет.
