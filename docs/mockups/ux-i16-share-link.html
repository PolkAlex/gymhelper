[UX-I16] · Read-only шейринг тренировки по ссылке

Пользователь делится ссылкой на свою конкретную тренировку; друг тапает и видит read-only страницу в любом браузере — без входа. Макет: публичная страница, страница «недоступна», шит выбора «Картинка / Телеграм», тост «Ссылка скопирована».

Одна ссылка для всех: в Telegram https-ссылка открывается во встроенном браузере — у юзера и не-юзера страница выглядит одинаково. Чужая тренировка не попадает в данные друга: закрыл страницу — вернулся в чат, «История» тут ни при чём. Спека: docs/spec-ux-i16-share-link.md.

1 · Публичная страница тренировки друг открыл ссылку

Стиль лендинга (тёмная Amber Glass). Состав: дата → герой-число (объём) → плашка рекорда реальным весом (решение 19.11) → агрегаты тремя карточками → все упражнения (у лучшего сета 🏆) → серия → строка приватности → sticky CTA. Имени владельца, питания и часов начала нет (ПДн-минимализм, §5 спеки).

Ключевые решения (полностью — spec-ux-i16-share-link.md)
  • Одна веб-страница вместо трёх сценариев: покрывает юзера, не-юзера, Telegram и любой браузер; read-only режим внутри Mini App (startapp) — overengineering, отсечён в v1.
  • Пункт «Телеграм» (редакция 2) заменил чистое копирование: буфер → выбор чата через t.me/share/url (Telegram показывает превью по OG-тегам) → тост «Ссылка скопирована»; без буфера — только выбор чата.
  • «Дальше что»: никакого «крестика → История». Закрытие возвращает в чат, откуда открыли; чужая тренировка в данные друга не копируется никогда.
  • shareId: 22 символа base62 (~131 бит), создаётся лениво, переиспользуется; страница noindex (мета + X-Robots-Tag + robots.txt); удаление тренировки/данных = смерть ссылки (404 «Тренировка недоступна»); отзыв и срок — v2.
  • Рекорд — реальным весом («120 кг», решение 19.11), Эпли на публичной странице не показываем; серия — «N тренировок подряд» до даты этой тренировки.
  • Не показываем: имя/username/фото, кастомное название, питание, часы начала–конца, вес тела и профиль (вопрос об opt-in имени — владельцу).
  • Рендер живой: правки владельца после шеринга видны на странице (честность данных), страница без JS — серверный HTML.
