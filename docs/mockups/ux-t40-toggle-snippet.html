[UX-T40] #295 · Разминка по дефолту

Решение владельца (19.11.2026): выбор первого упражнения — за пользователем. В Настройках карточка «🏋️ Тренировка»: тоггл «Разминка первым упражнением» (дефолт — выкл) и селектор упражнения (виден при включённом тоггле). По умолчанию — обобщённая запись «Разминка», дальше — упражнения каталога с тегом cat:warmup по возрастанию метаболической нагрузки. Спецификация: docs/spec-ux-t40-warmup-toggle.md (ред. 2). Черновик, не прод.

2 · Тоггл включён селектор свёрнут

Под тогглом появляется строка «Упражнение разминки» со значением. Дефолт — обобщённая запись «Разминка» (решение владельца «по умолчанию — Разминка»; точного упражнения с таким именем в каталоге нет — это системная запись, поддержанная фильтром isWarmupName). Настройка живёт в GymData: warmupFirst + warmupEx (null = «Разминка»).

1 · Разминка разминка · без подходов

Дальше — обычный список: «+ Упражнение», каталог, свои упражнения. Разминку можно удалить — повторно она не вернётся до следующего старта.

3 · Селектор раскрыт нижний лист «Упражнение разминки»

Первый пункт — системная «Разминка» (подпись «по умолчанию»), затем упражнения каталога с тегом cat:warmup по возрастанию met: лёгкие вращения (2.0–2.5) → кардио-разминка 3.0 → приседания без веса 3.8 → прыжки/джампинг-джек (7.0–8.0). У выбранного пункта янтарная рамка и точка-отметка; тап — выбор + закрытие листа. Категории «Разминка» и коллекция «Разминка и заминка» в списке НЕ участвуют (это не упражнения).

Примечания (решения владельца 19.11.2026)
Дефолт «Разминка» — системная запись: не навязывает тип разминки; время входит в тренировку через started (модель [UX-T15]); справочный MET 2.5 — на случай справочных расчётов.
Не пересекается с «🤸 Разминка 10 мин» [UX-T15]: там сдвиг времени, здесь упражнение; включены оба — применяются оба.
Хранение: warmupFirst (Boolean, null=выкл) + warmupEx (id каталога, null=«Разминка») в GymData — старые файлы без ключей читаются.
Макет статичный; тогглы и пункты листа некликабельны (демонстрация состояний).
