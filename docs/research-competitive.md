## 5. Gap-анализ GymHelper

### 5.1. Чего не хватает (главные разрывы)

| Разрыв | Важность | Комментарий |
|---|---|---|
| Таймер отдыха | Критично | Единственная фича, которая есть у **всех** лидеров и всех мелких игроков. В зале телефон в руке всё время между подходами — таймер удерживает приложение открытым |
| Шаблоны тренировок | Критично | Главный функциональный разрыв с лидерами. Без шаблонов GymHelper — «чистый журнал», а рынок уходит в «журнал + план». Тикетов на доске нет — новая идея |
| Графики прогресса | Высокая | Данные в JSON уже есть — не хватает только визуализации (SVG в Mini App). Связь: #50–51 (аналитика) |
| Live-PR и 1ПМ | Высокая | Рекорды в статистике есть, но пользователь не получает эмоцию в момент ввода. Самая дешёвая «эмоция мотивации» из возможных |
| Прошлый вес в Mini App | Высокая | В боте сделано, в Mini App нет — #11/#43 уже в бэклоге, подтверждено рынком как must-have |
| Экспорт CSV | Средняя | Гигиена и доверие: «мои данные — мои». Плюс страховка от наших же сбоев |
| Цели + напоминания | Средняя | #13 уже в бэклоге — рынок подтверждает (FitNotes goals, стрики Hevy) |
| Динамика веса тела | Средняя | Профиль хранит один вес; замеры с датой = маленький шаг к «замерам тела» конкурентов |

### 5.2. Где конкуренты переусложнены (наши возможности)

| Конкурент | Переусложнение / слабость |
|---|---|
| Hevy | «overbuilt» — прямая формулировка из Reddit-синтеза: соцфид, Trainer, ИИ, лимит 150 сетов, free-тир с 4 лимитами одновременно |
| Strong | графики — только в PRO; 3 шаблона бесплатно |
| JEFIT | «UI датирован, нет причины начинать с него в 2026» (Reddit-синтез); Elite $12.99/мес |
| Liftin' | free = 5 тренировок/мес — агрессивный пейволл для новичка |
| SmartWorkout | подсказки прогрессии — платные; ИИ-кредиты |
| Все сразу | подписки + ИИ везде; интерфейс «лента → кнопки» — никто не делает диалог как интерфейс |

### 5.3. Наши дифференциаторы (не терять при развитии)

1. **Ввод одной строкой** «45кг, 4 по 12» — по Reddit-свидетельствам скорость ввода
   — фактор №1, у нас он закрыт лучше, чем у большинства.
2. **Telegram-нативность**: не надо качать приложение из стора, нет регистрации,
   работает на телефоне/десктопе/вебе мгновенно. На РФ-рынке это двойной плюс:
   **Hevy в российском App Store отсутствует** (SmartWorkout, 03.11.2026), а оплата
   зарубежных подписок из РФ затруднена — ниша «бесплатный дневник без стора» открыта.
3. **Бесплатное ядро** — точное попадание в фактор №4 (недоверие к пейволлам).
4. **Русский язык** и RU-поддержка (RuStore-конкуренты показывают спрос).
5. **Бэкапы на сервере** — у FitNotes/Strong данные только локальные, смерть телефона
   = потеря истории; у нас история переживает всё.

## 9. Что НЕ делаем и почему

| Не делаем | Почему |
|---|---|
| Соцсеть: лента, публичные профили, лайки | Боль №11: поляризует («отвлекающий шум»), дорого модерировать, чужая территория — Telegram сам соцсеть. Достаточно шеринг-карточки и (позже) «друзей» из #56 |
| Apple Watch / Wear OS приложение | Telegram не открывает Mini App на часах; нативное watch-приложение = второй продукт вне нашей экосистемы. Альтернатива — быстрый ввод через бота |
| Нативные приложения вне Telegram | Размывает позиционирование; весь смысл — «дневник внутри Telegram» |
| ИИ-тренер / автопрогрессия сейчас | Территория JEFIT Elite/SmartWorkout Premium/Liftin — конкурировать нечем и незачем на нашей стадии; шаблоны (спринт 4) закрывают «дать план» без ИИ |
| Пейволл на ядро (ввод, история, статистика) | Боль №6: недоверие к пейволлам — наш главный дифференциатор. Монетизация Stars (#1) — только вокруг: графики повышенной красоты, темы, облачные фичи сверх бесплатного ядра |
| Реклама | Дневник — приватное пространство; реклама убьёт доверие (см. отношение Reddit к монетизации) |
| Кардио-трекинг (дистанция/время/скорость) | FitNotes/JEFIT это умеют, но это другой класс тренировок; Strava уже занял нишу. Оставляем фокус «железо» |
