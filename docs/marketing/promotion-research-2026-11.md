# Продвижение GymHelper — исследование инструментов и каналов (ноябрь 2026)

*Дата: 24–25.11.2026. Два независимых исследования (нейронки для контента; MCP/скиллы/каналы) + перепроверка доступности под Беларусь + живые сетевые тесты с машины владельца (BY-IP).*
*Рамка: владелец — из Беларуси, контент публикует ЛИЧНО (подготовка — с ИИ-ассистентами), бюджет 0 ₽. Хабр/vc/пикабу исключены. Основной фронт — Instagram.*

## 3. Картинки: обложки, карусели, карточки

**Схема прав:** у бесплатных генераторов права обычно некоммерческие, а кириллицу ИИ рендерит плохо → **фон генерирует ИИ, текст наносит человек** в редакторе. Это и лицензионно чище, и без опечаток.

| Задача | Инструмент | Примечание |
|---|---|---|
| Фоны (без лимита) | **Kandinsky 6.0 через VK-бот GigaChat** | веб-GigaChat из РБ не залогиниться; VK-бот — серая зона (резерв) |
| Фоны/стилизация | **Алиса** (до 4 вариантов/запрос), **Qwen** | Qwen умеет текст на картинке |
| Фоны без ключа и GPU | **MCPollinations** (github.com/pinkpixel-dev/MCPollinations) | API Pollinations; проверено 24.11.2026 с BY-IP: HTTP 200, image/jpeg |
| Карусели/карточки/обложки | **Supa** (supa.ru) — free без карты, шаблоны | RU-аналог Canva; Canva из РБ не полагаться (статус не подтверждён) |
| Логотип/аватар/текст на картинке | **Ideogram** (ideogram.ai) | коммерческое разрешено; ~10 запросов/день; генерации публичны; регистрацию с +375 — «проверить» при первом входе |
| Черновые картинки | Bing Image Creator | 15 быстрых/день; водяной знак; «развлекательный» статус — не для «лица бренда» |
| Дозапас | Leonardo.ai (150 ток./день) | регистрацию проверить |
| **НЕ использовать** | Recraft | по условиям free **владелец картинок — Recraft** |

## 4. Видео / монтаж / озвучка / музыка

**Пайплайн «Reels за вечер без навыков монтажа»:** сценарий (В2, 10 мин) → съёмка/b-roll по плану (30 мин) → монтаж в CapCut (30–40 мин) → озвучка (15 мин) → субтитры → музыка из библиотеки Instagram.

| Этап | Инструмент | Комментарий |
|---|---|---|
| Монтаж | **CapCut** (телефон; из РБ — и десктоп) | автосубтитры (85% Reels смотрят без звука — обязательны), экспорт без знака при ручном монтаже; ИИ-функции могут отключаться по региону — «проверить» на своих задачах; критичные шаблоны хранить локально |
| ИИ-видео (b-roll) | **Qwen** (40 кр./день), GigaChat-видео (VK-бот, резерв), Dreamina (dreamina.capcut.com, ежедневные кредиты) | Kling (66 кр./день)/Hailuo/Runway — только пробы: free-ролики с водяным знаком и запретом коммерческого использования |
| Озвучка | **Silero — ТГ-бот @silero_voice_bot** (бесплатно); апгрейд: Yandex SpeechKit ~7 ₽/ролик | у Silero для коммерческого использования — версии `v5_cis_base` (MIT); уточнить условия бота; SpeechKit: оплату с BY-карты — «проверить». ElevenLabs/SaluteSpeech — недоступны/закрыты |
| Музыка | библиотека Instagram (в приложении — безопасно для органики); для VK — библиотека VK | «обычная» библиотека CapCut запрещает коммерческое; Pixabay из РБ закрыт; Freepik — 10 файлов/день с атрибуцией |
| Стоки | **Life of Pix, Skitterphoto (CC0), SplitShire, Burst, RuPixel** | Pexels/Pixabay/Unsplash из РБ закрыты |

Реалистичный тайминг: первый Reels 1,5–2 часа вечером; на набитой руке 40–60 минут.

## 5. Публикация (владелец постит сам)

- **Нативный планировщик Instagram** — профессиональный аккаунт, отложка до 75 дней, работает из РБ без VPN. Базовый вариант.
- Buffer Free / Metricool Free — только как контент-календарь и черновики (при росте регулярности).
- **Автопостинг запрещён** (решение владельца + риск): с апреля 2026 Instagram агрессивно раздаёт Account Integrity Ban за признаки автоматизации; instagrapi и сервисы, просящие логин-пароль, — прямой путь к бану.
- Лимиты площадки: **5 хештегов на пост** (с 12.2025), описание до 2200 знаков, профиль → «Статус аккаунта» проверять раз в месяц.
- Новый аккаунт: 1 пост/день первые 2–4 недели, stories 2–3/день, без резких скачков активности; стабильная география входа (всегда из РБ).

## 7. Каналы первых пользователей (сортировка по скорости при 0 ₽)

### 7.1 Telegram Apps Center (tapps.center) — ВЕС-1
- Подача через **@app_moderation_bot**: ссылка → analytics ID → подзаголовок ≤60 знаков → EN-описание (по образцу каталога) → 2–6 скриншотов 9:19.5. Бесплатно, без карты.
- **Жёсткий гейт: TMA Analytics SDK** (github.com/Telegram-Mini-Apps/analytics) — без него отклоняют сразу. Тикет [PRO-T1].
- Кейс 04.2026: DAU +300%, новые юзеры +479% нед/нед после листинга. Модерация ручная: неделя–три.

### 7.2 Каталоги ботов + SEO Telegram (один вечер — фон навсегда)
| Каталог | Действие |
|---|---|
| telegram.botlist.ru | «Добавить» |
| telegram.org.ru/telegram-bots | /add |
| storebot.me | Submit Bot (EN-описание) — доступность из РБ проверена 24.11: HTTP 200 |
| botostore.com | найти канал подачи |
| tgstat.com | карточка + база для отбора каналов |

Перед подачей: бот мгновенно отвечает на /start, заполнены About/Description в BotFather, аватар, метка `?start=<каталог>` в ссылке. Ожидание: единицы переходов в день после индексации.

### 7.3 Взаимопиар (неделя 2–3, когда в канале 5–7 постов)
- Поиск TGStat: тематика «фитнес/ЗОЖ/бег» + смежные; **ERR ≥10%**; охват поста ±10–30% от нашего; 3–5 партнёров (не «подборки 5+»); личка админу по скрипту → одновременный постинг → пригласительные ссылки.
- Проверка кандидатов на накрутку: медиана просмотров 10 постов старше 48ч vs подписчики.
- Не спамить ВП-чаты; не брать ботов, требующих права админа канала.

### 7.4 Instagram Reels + карусели — главная органика RU+BY
- Форматы: обучающие мини-ролики 15–30 сек («3 ошибки в приседе», «как считать 1ПМ»), миф-vs-факт, «сохрани, чтобы не потерять» (RU-аудитория сохраняет чаще всех стран), до/после.
- Частота: **2–3 Reels/нед на старте → 3–5** + stories ежедневно + карусели (сохранения).
- Время: 6:00–8:00 и 19:00–20:00 (Минск = МСК — покрывает и РФ).
- Хук = первые 2–3 секунды: цифра+результат («Сохрани: −8 кг за 12 недель»), POV:, непопулярное мнение.
- Хештеги: 3–5 нишевых (#дневниктренировок #1ПМ #программатренировок), **без гео-привязки** (аудитория RU+BY), наборы не повторять.
- CTA: «ссылка в шапке профиля» (прямых ссылок в Reels нет) → `https://t.me/MyHelperGymBot?start=instagram`.
- Trial Reels (тест на не-подписчиках) — использовать. Каждый Reels дублировать в TG-канал и VK (страховка охвата: часть RU-зрителей через VPN).

### 7.5 Комментинг (20–30 мин/день, отдача с месяца)
- TG: 10–20 живых чатов («фитнес», «качалка», «ЗОЖ», «похудение») — отвечать по делу; бот упоминается только когда спрашивают «чем вести дневник» (реклама в чате = бан).
- Форумы (живы в 2026): forum.athlete.ru («Для новичков», дневники), forum.ironman.ru, do4a.org, forum.steelfactor.ru.
- Ожидание: месяц работы → 10–30 целевых пользователей.

### Не тратить время
Product Hunt (RU-only продукт — кейсы «ноль»), Reddit (нет RU-аналога), накрутки, «100 каталогов за деньги».

**Прогноз при 0 ₽: 100–300 пользователей за 2–3 месяца.** Каждая точка входа — своя метка `?start=` (атрибуция).

## 8. Промпты-воркфлоу (копировать в DeepSeek/Qwen/Алису)

**В1. Идеи постов на неделю:**
```
Ты SMM-редактор. Продукт: GymHelper — бесплатный Telegram-бот, дневник тренировок
(254 упражнения с фото, календарь, рекорды, 1ПМ, таймер отдыха, без регистрации).
Аудитория: русскоязычные любители фитнеса в Instagram.
Задача: 7 идей постов на неделю по ролям: 2 пользы (совет по тренировкам),
2 продукта (фича бота через боль пользователя), 1 соцдоказательство (анонимная
история спортсмена), 1 мотивация, 1 интерактив (опрос/вопрос).
Формат для каждой: тема, боль, формат (Reels/карусель/пост), первая строка-хук.
Факты о продукте бери только из описания выше, ничего не выдумывай.
```

**В2. Сценарий Reels 15–30 сек:**
```
Напиши сценарий Reels на 20 секунд. Тема: [тема]. Продукт упоминается один раз в конце.
Структура с тайм-кодами: 0–3 сек хук (текст на экране + действие в кадре),
4–15 сек суть (3 короткие фразы, каждая — новый кадр), 16–20 сек CTA
(подписка/попробовать бота — без прямой ссылки, ссылка в био).
Отдельно дай: текст на экране по кадрам (до 6 слов на кадр), что снимать
(план съёмки с телефона), описание под пост до 900 знаков.
```

**В3. Рерайт под тон бренда:**
```
Перепиши текст в стиле примеров ниже. Правила: третье лицо про продукт,
без «ты/вы», короткие фразы, факты без обещаний, без канцелярита и слов
«уникальный/инновационный», один абзац — одна мысль.
Примеры тона: [2–3 поста]. Текст: [черновик]. Длина как в оригинале ±10%.
```

**В4. Хештеги и описание:**
```
К посту [вставить] дай: 1) описание до 900 знаков с вопросом в конце;
2) 5 хештегов: 2 широких фитнес-тематики RU, 2 узких (дневник тренировок,
тренировка дома), 1 нишевый под тему поста. Одинаковые наборы под разными
постами не давать — состав под каждую тему свой.
```

## 9. Юридический блок (РБ, кратко — финальную трактовку дать юристу)

- **Реестр рекламораспространителей МАРТ не нужен** для постов о собственном продукте в собственных аккаунтах (официальный ответ МАРТ, вопрос 5415; Закон РБ №225-З «О рекламе» в ред. №353-З, реестр действует с 12.07.2024).
- Открытый вопрос: нужна ли пометка «реклама»/УНП в постах с призывом «попробуйте» — продукт бесплатный, «приобретения» нет (серая зона); статус владельца (физлицо/ИП). Свериться с памяткой МАРТ для блогеров от 14.11.2026 (belta.by).
- **Платные посевы/интеграции** — только после юр. проверки: у исполнителя возникает обязанность по Реестру, у владельца — требования к рекламодателю. Для РФ-аудитории: запрет рекламы на Meta-площадках (закон РФ с 01.09.2025) и маркировка ЕРИР — к органике резидента РБ не применяются, к платным механикам применимы.
- Язык рекламы в РБ: белорусский и/или русский — RU-тексты соответствуют.
