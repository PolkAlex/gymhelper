# 💪 MyHelper — Telegram-бот: дневник тренировок

[![CI](https://github.com/PolkAlex/gymhelper/actions/workflows/ci.yml/badge.svg)](https://github.com/PolkAlex/gymhelper/actions/workflows/ci.yml)

Бот для записи занятий в тренажёрном зале, по аналогии с мобильными приложениями
(Strong, Hevy): пошаговый ввод упражнений с подсказками, история, статистика,
расчёт калорий и прогресс от тренировки к тренировке.

Написан на чистой Java 17 без внешних зависимостей.

## Возможности

- 🏋️ **Тренировка** — фиксируются дата и время начала, при завершении — время конца и длительность
- 🧙 **Пошаговый ввод** — бот спрашивает:
  1. вес — кнопками с **прошлой тренировки** и **самый популярный** (★), можно свой (`50, 80`, `100-260`)
  2. количество подходов
  3. повторения — кнопками с прошлого раза (число, `8-10`, `макс`, `5+1`)
  - лайфхак: всё одной строкой `45кг, 4 по 12` прямо на шаге веса
- ✏️ **Редактирование** — можно изменить вес/подходы/повторы любой записи, переименовать
  упражнение или удалить запись; работает и для завершённых тренировок
- 🏷 **Название тренировки** — авто (4 строки: жирные дата ДД-ММ и день недели + первые 3 упражнения)
  или своё; меняется кнопкой «🏷 Название»
- 👀 **Посмотреть тренировку** — все упражнения за сегодня или за последнюю тренировку
- 🥤 **Питание** — что пил и ел во время тренировки (кнопка «Питание»)
- 🔥 **Калории** — расчёт по формуле MET (Compendium of Physical Activities):
  `ккал = MET × 3.5 × вес(кг) ÷ 200 × минуты`
  - MET по интенсивности (объём кг/мин): <120 → 3.5 (низкая), 120–300 → 5.0 (средняя), >300 → 6.0 (высокая)
  - длительность в расчёте ограничена 240 минутами
  - нужен профиль (вес); рост/возраст/пол используются для BMR (Mifflin-St Jeor)
- 📈 **Прогресс** — сравнение с предыдущей тренировкой: длительность, ккал и по каждому
  упражнению (вес и подходы)
- 📜 **История** — список с пагинацией (кнопки вида «📅 26-10 ПН»), просмотр, удаление
- 📊 **Статистика** — общее время и подходы, максимум и последняя запись по каждому упражнению
- 💾 Данные хранятся локально в папке `data/` (по одному JSON-файлу на чат)
- Незавершённая тренировка не теряется — бот предложит продолжить или начать новую

## Настройка

1. В Telegram найди **@BotFather** → команда `/newbot` → придумай имя → получи токен вида `123456:ABC-DEF...`
2. Передай токен боту одним из способов:
   - переменная окружения `GYM_BOT_TOKEN`, **или**
   - файл `token.txt` в корне проекта с токеном внутри

⚠️ Не публикуй токен (не коммить `token.txt` — он уже в `.gitignore`).

## Запуск

### В IntelliJ IDEA
Просто запусти `src/gym/Main.java` (зелёный треугольник рядом с `main`).

### Из консоли (PowerShell)
```powershell
# через Gradle (сборка + контрактный тест + jar)
.\gradlew.bat --no-daemon build
java -jar build\libs\gymhelper-1.0.0.jar

# по-старинке, без Gradle
javac -encoding UTF-8 -d out (Get-ChildItem -Recurse src -Filter *.java).FullName
java -cp out gym.Main
```

Остановить бота — `Ctrl+C`.

### Docker (VPS или локально с Docker Desktop)
```powershell
# токен в файл .env (в .gitignore): GYM_BOT_TOKEN=123456:ABC-DEF...
# пакет приватный: перед pull нужен docker login ghcr.io (PAT с read:packages)
docker compose pull               # образ из ghcr.io (публикует CI на push в main)
docker compose up -d              # запуск, data/ в том же месте
docker compose logs -f           # логи
docker compose down              # остановить
```

## 📱 Telegram Mini App (приложение)

Бот поднимает встроенный веб-сервер (порт `8080`, меняется через `GYM_PORT`) и раздаёт
мини-приложение из папки `web/`. Данные общие с ботом — те же `data/*.json`.
Доступ защищён подписью Telegram (`initData` проверяется HMAC-SHA256 токеном бота).

### Включение приложения

1. Запусти бота — сервер поднимется на `http://127.0.0.1:8080`
2. Telegram требует публичный **HTTPS**-адрес, поэтому нужен туннель или хостинг:

**Вариант А — быстрый тест (cloudflared, без регистрации):**
```powershell
# скачать cloudflared: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
cloudflared tunnel --url http://127.0.0.1:8080
# скопировать выданный адрес вида https://xxx-yyy.trycloudflare.com в файл webapp.txt
# перезапустить бота
```
Адрес меняется при каждом перезапуске туннеля — обновляй `webapp.txt` и перезапускай бота.

**Вариант Б — постоянный адрес (ngrok):** зарегистрируйся на ngrok.com, получи
бесплатный статический домен, затем:
```powershell
ngrok config add-authtoken <token>
ngrok http --domain=xxx.ngrok-free.app 8080
# домен в webapp.txt, перезапустить бота
```

**Вариант В — VPS:** запусти бота там, поставь nginx с HTTPS (certbot) и проксируй
на `127.0.0.1:8080`; адрес в `webapp.txt` (или env `GYM_WEBAPP_URL`).

3. Открой чат с ботом → кнопка меню **☰ → «🏋️ Дневник»** (регистрируется автоматически,
   если в `webapp.txt` есть https-адрес)

Бот и приложение работают одновременно: записал тренировку в приложении — она видна
в боте, и наоборот.

## Использование

1. Открой своего бота в Telegram → `/start`
2. «⚙️ Профиль» → введи `пол возраст рост вес` (например `м 30 180 82`) — нужен для ккал
3. «🏋️ Начать тренировку» → выбери упражнение → вес (кнопки-подсказки) → подходы → повторения
4. «➕ Ещё запись» / «✏️ Редактировать записи» / «🏁 Закончить упражнение»
5. В любой момент: «🥤 Питание», «⏱ Время», «🏷 Название», «📈 Прогресс», «🔥 Ккал»
6. «✅ Завершить» — зафиксируется время конца и длительность
7. «👀 Посмотреть тренировку» — сегодня или последняя; «📜 История» — все тренировки

Команды: `/start`, `/workout`, `/view`, `/history`, `/stats`, `/profile`

## Структура проекта

```
src/gym/                — Java-код бота (без внешних зависимостей)
├── Main.java          — точка входа, цикл long polling
├── BotLogic.java      — вся логика бота (мастер ввода, редактирование, ккал, прогресс)
├── TelegramApi.java   — клиент Telegram Bot API (HTTP, HTML parse_mode, inline-клавиатуры)
├── Json.java          — мини-парсер/сериализатор JSON
├── GymData.java       — модель хранилища (профиль + тренировки, сериализация)
├── Workout.java       — тренировка (дата, время начала/конца, название, питание)
├── ExerciseEntry.java — упражнение (название + записи)
├── SetEntry.java      — запись (вес, подходы × повторы)
├── ProfileData.java   — профиль (пол, возраст, рост, вес)
├── Exercises.java     — каталог упражнений (личный список)
├── Storage.java       — загрузка/сохранение данных в data/*.json
├── UserState.java     — состояние диалога (шаг мастера, редактирование, подсказки)
└── web/WebServer.java — HTTP-сервер Mini App (статика + API + проверка initData)

web/ (корень)           — index.html, app.js, catalog.js, style.css — фронтенд приложения
tests/                  — e2e.spec.js (Playwright), GymContractTest.java, check.js, server-test.js
.github/workflows/ci.yml — CI: сборка + контрактный тест + e2e на 4 устройствах
build.gradle / gradlew  — сборка Gradle (jar: build/libs/gymhelper-1.0.0.jar)
Dockerfile / docker-compose.yml — контейнер для VPS
docs/                   — дизайн-спецификации, макеты, карта покрытия тестами
```
