## Самопроверка по скиллу avoid-ai-writing (1 проход + правка)

- Найдено и исправлено в черновике: канцелярный оборот «и готовить их нужно одинаково»
  переписан («нагружаются всегда — и у новичка, и у опытных»); гипотетическая цифра
  «после пяти лет в зале» убрана по правилу «ничего не выдумывать».
- P0/P1 находок в финале нет: нет канцелярита, «уникального/инновационного», обещаний
  результата, engagement bait; зачин — прямое утверждение, не «в современном мире».
- Осознанные остатки (не правились): три мифа — структура хука-анонса списка,
  обещанная в первых секундах, а не «правило трёх» compulsive; дефиниционные тире —
  обязательны русской типографикой; «Пять минут до штанги дешевле травмы» — речевая
  фигура без выдуманных сроков и процентов.
- Аудит ручной (model-only): механический детектор оригинального скилла английский,
  на RU-текстах не запускался.

## Соответствие правилам канала

- Подпись 764 знака (лимит 900), вопрос в конце ✓
- Хештеги 2+2+1: #спорт #зож (широкие) / #техникаупражнений #тренажерныйзал (узкие) /
  #разминка (нишевый); набор новый, не повторяет пакет 2026-11-25-1pm ✓
- Факты только общеизвестные о разминке, без ссылок на исследования и без цифр «из воздуха» ✓
- Продукт упоминается один раз в конце ролика и один раз в подписи, третье лицо,
  формулировка «254 упражнения, 224 с фото техники» ✓
- CTA без прямой ссылки («ссылка в шапке») ✓
- Публикация — вручную владельцем (автопостинг запрещён) ✓
