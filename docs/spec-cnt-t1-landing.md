## 1. Цель и пользовательская проблема

**Проблема.** Продукт готов, но внешний человек, получивший ссылку (из поста в чате,
шеринг-карточки, README, статьи), попадает на health-заглушку или Mini App без контекста.
Нечего показать: ни «что это», ни «зачем мне», ни кнопки «попробовать». Дистрибуция —
главный гэп продукта (анализ §4, п.1), и все будущие каналы (шеринг-карточки, каталог
Mini Apps, посты) упираются в отсутствие витрины.

**Цель лендинга.** Внешний человек за **30 секунд** понимает: это дневник тренировок
внутри Telegram, без установки и регистрации, бесплатно — и нажимает «Запустить в
Telegram». Одна страница, один главный сценарий, один CTA.

**Метрика успеха** (когда появится счётчик, см. вопрос 3): клики по кнопке «Запустить»
→ диалог с ботом (первый /start из внешнего источника).

**Аудитория.** Русскоязычные посетители из Telegram-ссылок (мобильные — большинство),
GitHub-читатели, участники фитнес-чатов. Лендинг — RU-only (EN — после доказательства
TG-ниши, анализ §8).

## 2. Позиционирование (что продаём в первом экране)

Из анализа §3–4, по силе:

1. **Ноль трения входа** — не ставить приложение, не регистрироваться; кнопка → диалог
   с ботом; онбординг ~60 секунд. Конкуренты (Strong, Hevy, JEFIT) теряют аудиторию
   именно на установке.
2. **Двойной интерфейс** — бот-чат + Mini App, уникально на рынке.
3. **Приватность в ДНК** — свой VPS, ноль трекеров, право на забвение командой.
4. **Каталог 254 упражнения** (224 с фото из free-exercise-db, Unlicense) с техникой
   и фильтрами по мышцам/инвентарю.
5. **Полный цикл бесплатно** — календарь-сетка месяца, e1RM по Эпли, живые рекорды,
   калории по MET, таймер отдыха, шаблоны, экспорт CSV.
6. **Открытый код** — github.com/PolkAlex/gymhelper.

Честные ограничения (Telegram-платформа: нет офлайна, Apple Watch, пульса) на лендинг
**не выносим** — не потому что скрываем, а потому что целевой посетитель приходит из
Telegram и этих ожиданий не приносит. Ответы на скепсис — в FAQ-будущем (не v1).

## 3. Размещение (архитектура) — открыто, вопрос 1

Сейчас: nginx на VPS терминирует gym-helper.com и проксирует на контейнер (порт 8080),
корень `/` отдаёт Mini App (`index.html`), есть `/health` и `web/privacy.html`.

Варианты:

| | Вариант | Плюсы | Минусы |
|---|---|---|---|
| **(a)** | Лендинг в **корне** gym-helper.com (статика nginx), Mini App переносится на **app.gym-helper.com** | «Чистый» брендовый корень — все внешние ссылки короткие; лендинг не зависит от Java-сервера | Миграция URL Mini App: webapp.txt/BotFather, перенастройка nginx; делать сейчас дёшево (шеринг-карточек ещё нет), позже — дороже |
| (b) | Лендинг по пути **gym-helper.com/about** (или `/landing`), Mini App остаётся в корне | Нулевой риск для работающего Mini App | Некрасивый URL для витрины; «/about» неочевиден как главная |
| (c) | Поддомен **land.gym-helper.com** | Не трогаем ни корень, ни приложение | Два домена в OG-превью, ссылка длиннее, SEO размывается |

**Рекомендация дизайнера: (a)** — корень должен быть витриной (это общепринятая
анатомия продукта), а миграция сейчас — одна правка webapp.txt + BotFather + блок
location в nginx. Но решение за владельцем (вопрос 1). Макет от варианта не зависит:
он рисует страницу, URL — вопрос деплоя.

## 4. Структура страницы и тексты (RU)

Один `<main>`, 8 секций сверху вниз. Тексты ниже — финальные для макета; мелкие правки
допустимы при реализации, смысл — нет. Тональность «вы» (строчная) — см. вопрос 4.

### 4.0 Шапка (sticky)

- Слева: логотип — янтарный тайл 36px с 💪 + «GymHelper» (жирный, 17px).
- Центр/право: якорные ссылки «Как работает · Возможности · Приватность · Код»
  (muted, hover — светлее).
- Справа: компактная CTA-кнопка «Запустить» (янтарный градиент) → `https://t.me/MyHelperGymBot`.
- Стекло + blur (как topbar продукта), при скролле остаётся сверху.
- Мобайл: ссылки навигации скрываются, остаются логотип + кнопка.

### 4.1 Hero — первый экран («что это и зачем за 10 секунд»)

- **H1**: «Силовой дневник, который живёт в Telegram»
- **Подзаголовок**: «Никаких установок и регистраций: нажали кнопку — записываете
  подходы. GymHelper сам посчитает рекорды, объёмы и калории.»
- **Кнопка (главная, янтарный градиент)**: «Запустить в Telegram» →
  `https://t.me/MyHelperGymBot` (в новом окне, rel="noopener").
- **Вторичная ссылка**: «Что умеет ↓» — якорь на #features (прозрачная кнопка).
- **Строка-доверие под кнопкой** (muted, 13px): «Бесплатно · Без регистрации · По-русски»
- Справа: **плейсхолдер скриншота** — телефонная рамка с пунктирной рамкой внутри
  («Mini App · экран „Сегодня“»), над ней декоративные плавающие пилюли продукта:
  «🏆 Рекорд! 1ПМ ≈ 102,5 кг» и «⏱ Отдых 1:30» (чистый CSS, передают язык продукта
  до появления скриншотов).
- Чипы под hero (тёмные капсулы): «Ноль установки» · «254 упражнения» · «1ПМ и рекорды» ·
  «Открытый код».

### 4.2 Как это работает — 3 шага

Заголовок секции: «Запуск — минута, привычка — надолго». Карточки с номерами 1–2-3
(янтарная цифра, стекло):

1. **«Нажмите „Запустить“»** — «Откроется диалог с ботом в Telegram. Короткое
   знакомство с дневником — около минуты.»
2. **«Запишите тренировку»** — «Выберите упражнение из каталога, укажите вес и подходы.
   Подсказки подставятся с прошлых разов, таймер отдыха запустится сам.»
3. **«Смотрите, как растёте»** — «Календарь, личные рекорды и оценка 1ПМ собираются
   без вашего участия. Дневник ведёт себя сам.»

### 4.3 Возможности — 6 карточек (#features)

Заголовок: «Всё, что нужно в зале — и ничего лишнего». Сетка 3×2 (десктоп) → 2 → 1
(мобайл). Каждая карточка: янтарный тайл-иконка (40px), заголовок, 2–3 строки.

1. 🏋️ **«Запись подхода за секунды»** — «Пошаговый ввод: упражнение → вес → подходы →
   повторения. Значения с прошлой тренировки подставляются сами. В чате можно и одной
   строкой: „80 кг, 4 по 10“.»
2. 🤖 **«Бот и приложение — одни данные»** — «Любите чат — пишите боту кнопками и
   командами. Любите экраны — откройте мини-приложение с каталогом, календарём и
   статистикой. Начали в чате, закончили в приложении.»
3. 📚 **«Каталог: 254 упражнения»** — «Фото, техника выполнения и фильтры по мышцам и
   инвентарю — от штанги до резинок, плюс кардио и растяжка. Своё упражнение — тоже
   можно.»
4. 📅 **«Календарь и история»** — «Месячная сетка с отметками тренировок: регулярность
   видна с одного взгляда. Вся история — под рукой, выгрузка в CSV в один клик.»
   *(Осознанно без «поиска по истории» — такой функции в продукте нет, обещать нельзя.)*
5. 📈 **«Статистика, которая мотивирует»** — «Оценка 1ПМ по формуле Эпли, живые рекорды
   с поздравлениями, прогресс по каждому упражнению и калории по MET.»
6. ⏱ **«Таймер и шаблоны»** — «Таймер отдыха запускается после каждого подхода. Типовые

### 4.4 Скриншоты (#screens)

Заголовок: «Как это выглядит». Три плейсхолдера-рамки (пунктир, янтарный отлив), внутри

## 5. SEO и метатеги

```html
<title>GymHelper — дневник тренировок в Telegram · без установки, бесплатно</title>
<meta name="description" content="Записывайте силовые тренировки в чате или
  мини-приложении Telegram: 254 упражнения с техникой, календарь, оценка 1ПМ
  по Эпли, рекорды и калории. Без установки и регистрации.">
```

- Один H1 на странице (hero); H2 — секции. lang="ru".
- **Open Graph** (критично: ссылку будут шерить именно в Telegram — превью решает):
  `og:title` = title, `og:description` = description, `og:type` = website,
  `og:url` = https://gym-helper.com/, `og:image` 1200×630 (карточка в стиле Amber Glass,
  логотип + слоган; готовит lead — вопрос 6). + `twitter:card` = summary_large_image.
- favicon: янтарная 💪-плитка (сделать на базе тайла логотипа, SVG или ICO+PNG).
- robots: индексация разрешена; sitemap не нужен (одна страница).
- Разметка Schema.org — не делаем (дополнительная сущность без измеримой пользы для
  одной страницы; пересмотр при росте).

## 6. Адаптив и доступность

**Десктоп-first** (посетители из GitHub/статей), но мобильный сценарий не хуже —
большинство придёт из Telegram-постов.

Брейкпоинты (ориентиры, не догма):
- ≥860px: hero в 2 колонки (текст слева, скриншот справа), фичи 3 колонки, шаги в ряд;
- 560–860px: hero в 1 колонку (скриншот под текстом), фичи 2, шаги в ряд/перенос;
- <560px: всё в 1 колонку, шапка без навигации (лого + «Запустить»), паддинги 16px.

Контейнер: max-width 1100px, паддинги 24px (мобайл 16px).

Доступность:
- контраст muted #9aa0aa на #101114 ≈ 6.8:1 — ок для основного текста;
- все интерактивные элементы — `<a>`/`<button>` с focus-visible (янтарный outline);
- semantic: header/main/section/footer, один h1, якоря;
- prefers-reduced-motion: отключить плавные появления (если будут — v1 можно без
  анимаций вовсе).

## 7. Требования к реализации (после одобрения макета)

Для кодера, коротко:

1. **Один статический файл** `landing.html` (или index.html — по решению вопроса 1):
   инлайн-CSS или рядом `landing.css`; **ноль JavaScript**, ноль внешних зависимостей,
   системные шрифты (как продукт). Фреймворки/веб-фонты/CDN — нельзя (конвенция web/).
2. **Палитра и стиль — Amber Glass** из `web/style.css`: bg #101114, янтарь #ffc220
   (градиент 135deg #ffb000→#ffc220 для кнопок), стекло rgba(255,255,255,.055) +
   бордер rgba(255,255,255,.10), тёплые радиальные градиенты фона (amb1–amb3),
   радиусы 14–20px, тени cta-shadow/glow. Лендинг должен узнаваться как родной
   продукт.
3. **Кнопки запуска** — обычные `<a href="https://t.me/MyHelperGymBot" target="_blank"
   rel="noopener">`. Внизу и в шапке — один и тот же адрес.
4. **Скриншоты** — файлы `img/landing/*.jpg|webp`, размеры зафиксировать атрибутами,
   loading="lazy". Рамки-плейсхолдеры из макета заменяются на `<img>` 1-в-1.
5. **Отдача** — статикой nginx (вариант по вопросу 1), gzip/brotli для html+css+img.
   Java-сервер не участвует.
6. **Проверки**: валидность HTML, Lighthouse-аудит вручную (цель: perf/a11y ≥ 95,
   без JS это достижимо), проверка OG-превью в Telegram (бот @WebpageBot для сброса
   кэша превью), 390px / 768px / 1280px вручную + Playwright-скрин по желанию tester'а.
7. **Не трогать**: прод-бот, Mini App, WebServer (кроме сценария (a) — миграция
   app.gym-helper.com отдельным тикетом инфраструктуры).

Edge cases страницы: без JS всё работает (его нет); картинки не загрузились — alt-текст
и фон рамки; очень узкие экраны (<340px) — колонки не ломаются (flex-wrap);
печать — не целевой сценарий.

## 8. Что НЕ делаем (отсечено)

| Отсечено | Почему |
|---|---|
| EN-версия, i18n | По анализу §8: EN — после доказательства TG-ниши |
| Отзывы/рейтинги/логотипы пользователей | Пользователей 6 — витрина отзывов будет пустой и неубедительной; вернуться после роста |
| Тарифы и блок «цена» | Монетизации нет; слово «бесплатно» без звёздочек (вопрос 8) |
| Живое демо Mini App на странице | Mini App работает только внутри Telegram — на лендинге покажем скриншоты |
| Светлая тема лендинга | Продукт тёмный по умолчанию, витрина несёт идентичность; лишняя сущность в v1 |
| Форма email-подписки, лидогенерация | Нет продукта для рассылки; противоречит приватности-месседжу |
| Cookie-баннер | Страница не ставит куки и не подключает трекеры — баннеру нечего регулировать |
| FAQ, дорожная карта, блог | v1 — одна мысль и один CTA; секции размывают 30-секундный сценарий |
| Счётчик третьих лиц (GA/Yandex) | Противоречит главному отличию (ноль трекеров); свой анонимный — вопрос 3 |
| Анимации/скролл-эффекты | Без JS они всё равно невозможны, а JS в v1 не нужен; скорость и простота важнее |

## 9. Вопросы владельцу

Спорное не решаю сам — нужно для финализации:

1. **Размещение** (§3): (a) лендинг в корне + Mini App на app.gym-helper.com
   *(рекомендую — сейчас миграция дешёвая)*, (b) лендинг на /about, (c) поддомен.
2. **Username бота для кнопок**: в issue — `@MyHelperGymBot`, но действующая
   `web/privacy.html` пишет «владелец бота GymHelper (@GymPolkhovichBot)». Какой
   username публичный? Если бот переименован — privacy.html обновить этим же релизом.
