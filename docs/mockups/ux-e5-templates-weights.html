Экран 5 · Бот — кнопка плана на шаге веса [UX-E5] · один тап = блок записан
В боте нет формы — план даётся кнопкой мгновенной записи блока (первый ряд, до подсказок прошлых весов) и строкой «📋 По плану…» в тексте. Тап по кнопке = сразу «✅ Записано: 60 кг, 3 подхода по 10» + таймер отдыха, как у обычного ввода. Быстрый ввод одной строкой («45кг, 4 по 12») работает как раньше. В редактировании записи кнопки плана нет. План без веса: «📋 По плану: без веса, 3 по 10». План без повторений — только строка, без кнопки.
