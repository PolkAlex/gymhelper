# IG Carousel — карусель 1080×1350 через Playwright

Материал/тема → выжимка (хук + структура слайдов) → HTML-слайды 1080×1350 →
Playwright headless: скриншот каждого слайда в PNG → папка с карточками.

Puppeteer из оригинального скилла НЕ используется (не ставится в репо). Рендер —
Playwright, который уже есть в проекте (`node_modules/playwright`) или через Playwright MCP.

## Шаг 1. Выжимка (перед HTML)

Определить и показать владельцу краткую сводку:

1. **Главная мысль** — одна фраза; вся карусель служит ей.
2. **Аудитория** — кто пролистывает ленту и почему остановится.
3. **Хук обложки** — фраза читателя про его боль, не вывод автора. Пример: «Каждый раз
   считаешь проценты от максимума в голове?» Не абстрактные «флоу/система/методика».
4. **Структура** — тип: обучающая / список / сравнение / история / миф-vs-факт.
   По одному слайду на мысль, 3–10 слайдов.

## Шаг 2. HTML-слайды

Один `.html` файл на карусель (или один файл со страницами 1080×1350). Стиль GymHelper —
тёмная тема: фон `#0f1115`–`#171a21`, акцент неон-зелёный `#39d353` (как в Mini App),
белый текст `#f0f6fc`, вторичный `#8b949e`. Шрифт системный крупный: заголовок 72–96px,
текст 40–48px, минимум воздуха, крупная цифра-акцент если есть.

Правила контента (из оригинального скилла, обязательны):

- **Обложка = резонанс, не резюме.** Сначала боль читателя, потом поворот.
- **Один слайд — одна мысль.** Две мысли → два слайда.
- **Никаких выдуманных цифр.** Статистика только из проверяемого источника; нет источника →
  замени на нецифровой хук или пометь `<!-- TODO: источник -->`.
- **CTA-слайд**: глагол действия + комментарий-«ключевое слово» (например «напиши МАКС
  — расскажу, как считать 1ПМ») + упоминание бота один раз.
- **Не ужимать текст уменьшением шрифта**: лучше разбить на два слайда.
- Бренд-подпись на каждом слайде: `@gymhelper` (владелец создаст аккаунт — см. PRO-T4).

Каркас слайда:

```html
<div class="slide">        <!-- 1080×1350, padding ~80px -->
  <div class="badge">1ПМ за 30 секунд</div>
  <h1>Крупный заголовок слайда</h1>
  <p>2–4 строки текста. Одна мысль.</p>
  <div class="num">02</div><!-- watermark-номер справа внизу -->
  <div class="brand">@gymhelper</div>
</div>
```

## Шаг 3. PNG через Playwright

Скрипт (node, запускается из корня репо — playwright уже в node_modules):

```js
// tools-подобный однофайловый скрипт: html → png
const { chromium } = require('playwright');
(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage({ viewport: { width: 1080, height: 1350 } });
  await page.goto('file:///' + process.argv[2].replace(/\\/g, '/'));
  await page.waitForTimeout(300); // шрифты
  const slides = await page.$$('.slide');
  for (let i = 0; i < slides.length; i++) {
    await slides[i].screenshot({ path: `slide-${String(i + 1).padStart(2, '0')}.png` });
  }
  await browser.close();
})();
```

Проверка переполнения: перед скриншотом в каждой `.slide` контент должен помещаться
(можно проверить `scrollHeight <= 1350` и сократить текст/разделить слайд, если нет).
Итог: `slide-01.png` … `slide-NN.png` (1080×1350) + превью-контакт-лист по желанию.

## Шаг 4. Подпись к посту

После карусели — подпись и хештеги через скилл sm-captions (CTA-слайд и подпись
используют одно и то же ключевое слово комментария).

## Чеклист

- [ ] Обложка — боль читателя, ≤ 10 слов
- [ ] Один слайд = одна мысль
- [ ] Все цифры с источником или убраны
- [ ] CTA: глагол + ключевое слово комментария
- [ ] 1080×1350, ничего не обрезано, текст не мельче 32px
- [ ] Тексты прогнаны через avoid-ai-writing
