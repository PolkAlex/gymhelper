# Avoid AI Writing — вычитка от ИИ-штампов

Задача — убрать из текста машинные паттерны, чтобы он читался как написанный человеком.
Оригинальный каталог (EN, 100+ паттернов): github.com/conorbronsdon/avoid-ai-writing,
`references/patterns.md`. Ниже — адаптация под русские тексты GymHelper; она calibrирована
на SMM-контент, не на академические тексты.

## Режимы

- **rewrite** (по умолчанию) — найти штампы и переписать текст.
- **detect** («просто флаги», «только найди») — перечислить находки с цитатами, текст не менять.
- **edit** («почисти файл X») — правки в файле минимальными точечными edit.

## Критичность (приоритет правок)

### P0 — убивать сразу
- Чат-бот артефакты: «Надеюсь, это помогло!», «Отличный вопрос!», «Конечно, вот...»
- Неопределённые источники: «эксперты считают», «как известно», «доказано наукой» (без ссылки)
- Раздувание значимости: «революционный», «уникальный», «инновационный», « game-changer»
- Обещания результата без оснований: «гарантированно», «ты точно похудеешь» — запрещено правилами бренда (факты без обещаний)

### P1 — явный ИИ-запах
- Канцелярит и штамп-слова: **является, осуществлять, данный, данный вид, в рамках, вследствие, в настоящее время**
- ИИ-словарь (RU-эквиваленты delve/leverage/robust): **использовать возможности, комплексный подход, эффективное решение, оптимизировать процесс, открывает возможности, ключевой момент**
- Шаблонные зачины: «В современном мире...», «В сегодняшнем быстром ритме жизни...», «Каждый из нас знает...», «Не секрет, что...»
- Переходы-коннекторы: «Давайте разберёмся», «Итак, перейдём к», «Теперь давайте рассмотрим», «Подведём итоги»
- Синоним-карусель в одном абзаце (одно понятие — три разных слова подряд)
- Списки из голых существительных без глаголов (5+ пунктов «сила, выносливость, мотивация, дисциплина»)
- «Правило трёх» compulsive: всегда ровно три примера, три пункта, три причины
- Кавычки-пустышки: слово «результат» в кавычках без причины

### P2 — полировка
- Тире-драматизм: длинное тире чаще 1 на 1000 знаков в художных паузах
- Общие концовки: «Будущее выглядит светлым», «Начни сегодня — и результат не заставит себя ждать»
- Риторические вопросы-заглушки подряд (2+ в одном тексте)
- Одинаковая длина абзацев (ритм метронома)
- Отказ от глагола-связки: «служит», «выступает в роли», «представляет собой» вместо «это»
- Хедж-стекинг: «возможно, потенциально, в какой-то мере» в одном предложении
- Слова-усилители пустышки: «реально», «действительно», «просто» без нагрузки

## Контракт правок

1. Кандидат-совпадение ≠ находка: проверить контекст правила и исключения. Умеренный штамп
   в кавычке-цитате или в DSL-разметке слайда — не трогать без авторизации.
2. Минимальные правки: менять только найденные куски, структуру и аргумент не перестраивать
   без явной просьбы.
3. Ничего не выдумывать: цифры, имена, даты — только из источника или правки владельца.
   Нет данных для конкретики — пометить `<!-- TODO: источник -->`, не заполнять догадкой.
4. Сохранять голос: если текст уже живой — сказать «чисто» и не полировать ради правок.
   Оригинальный ритм, разговорные связки и «шершавости» сохраняются.

## Никогда не добавлять (типичные «человечизаторы» = новый штамп)

- Выдуманный спикер: «я видел сотни таких случаев», «по моему опыту» — если в источнике этого нет
- Накрученные ставки: «в мире, где...», «как никогда раньше»
- Фальшивая конфронтация: «все говорят X, но это не так» — только если источник это аргументирует
- «Давайте будем честны», «Реально говоря», «Вот в чём дело»
- Стаккато: рубка нормальных предложений на фрагменты ради ритма
- Выдуманная конкретика: цифра/имя/дата, которых нет в источнике

## Воркфлоу rewrite

1. Прочитать текст целиком, отметить находки по P0→P1→P2 с цитатами.
2. Переписать: вырезать штампы, конкретизировать за счёт фактов ИЗ источника, один абзац — одна мысль.
3. Самопроверка: прогнать ещё раз по P0/P1. Остались ли ≥3 разных P1-штампа в одном тексте? → второй проход.
4. Отчёт: **Финальный текст** (один раз, без двух версий подряд) → **Изменения** (кратко) →
   **Проверка**: проходов N, что осталось и почему (или «чисто»). Детектор механический не запускать —
   он английский; помечать аудит как ручной (model-only).

## Тон GymHelper (поверх вычитки)

- Третье лицо про продукт: «бот ведёт дневник», не «я веду твой дневник»
- Короткие фразы, факты без обещаний, без «уникальный/инновационный»
- Один абзац — одна мысль; вопрос в конце подписи — для комментариев, не для красоты
