[UX-I4] Ввод повторений — макеты

Модалка записи (390px, тёмная тема Amber Glass). Экран 1 — как сейчас; экраны 2–3 — рекомендация: пилюля «🔁 Прошлый подход» (один тап = вес + подходы + повторения), чип «15» в ряду пресетов, свободный текст для диапазонов сохраняется. Спека: docs/spec-ux-i4-reps-input.md

  • Вес 60 подставился молча ([UX-T12]), а подходы и повторения — «1» и «1»: для 2-го подхода той же схемы нужно 2–3 правки (подходы, повторения).

Подходы
Повторения (например 12, 8-10)
  • Пилюля «🔁 Прошлый подход» — один тап подставляет вес + подходы + повторения прошлой записи. Частый кейс («2-й–4-й подход те же») ускоряется до 1 тапа, клавиатура не открывается.
  • Пилюля стоит на месте пилюли плана [UX-E5]: пока записей нет — «📋 План», после первой записи — «🔁 Прошлый подход» (взаимоисключаемо).
  • Автоподстановки по-прежнему нет — решение [UX-T12/T17] «повторения не подставлять молча» не реверсируется: поля меняются только по явному тапу.
  • Чип 15 добавлен в ряд пресетов (7 кнопок вместо 6, инкременты сохранены [UX-T26]). Значения 9/11/13/14 — редки, их закрывает пилюля или клавиатура.

Подтягивания

Вес, кг (0 — без веса)
Подходы
Повторения (например 12, 8-10)
  • Упражнение без веса: в пилюле короткая форма — «🔁 Прошлый подход: 3 × 8-10» (edge-кейс E6 спеки).
  • Диапазон «8-10» скопирован строкой как есть — формат данных не меняется, в карточке будет «3 подхода по 8-10 повторений».
  • После тапа пилюля остаётся видимой, но приглушённой — как пилюля плана («вернуть значения» повторным тапом).
  • Диапазон, введённый вручную: тап «8» → клавиатура «-10». Текстовые записи («до отказа») — только клавиатура, валидация ≤ 15 символов сохраняется.
