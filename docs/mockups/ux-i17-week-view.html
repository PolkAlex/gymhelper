Виды календаря: День · 3 дня · Неделя · Месяц · Год UX-I17 · rev.2 · ревизия по Outlook

Фидбек владельца 19.11 по ревизии 1: «давай что-то похожее на Outlook Mobile» — скоуп расширен до 5 видов. «Рабочая неделя» и «Расписание» из Outlook НЕ делаем — ровно пять. Общая механика: одна выбранная дата на все виды + вид (пикер — нижний лист, кнопка в шапке подэкрана). Сеточные виды (День / 3 дня / Неделя) — один движок с 1/3/7 колонками: полоса дней сверху (сегодня — glow-круг, открытый день — обводка, в «3 дня» окно подсвечено капсулой), сетка часов 0–24 со скроллом (высота часа 56/48/44), блоки тренировок в нашей янтарной палитре (НЕ синие), тап по блоку → карточка. Месяц — существующий [UX-S6] без изменений. Год — 12 мини-месяцев 3×4, год виден целиком. Плавающая пилюля «Сегодня» — когда открытая дата вне текущего дня/периода. FAB «+» в календаре не делаем. Демо-неделя: Пн 19:05 «Грудь + трицепс», Вт 17 «Жим лёжа» (без времени — капсула), Ср 08:40 «Ноги», Чт 19 (сегодня) идёт «Спина + бицепс» с 19:05, Пт 20 пусто, Сб 11:00 «Кроссфит» ∩ 12:00 «Велосипед · длинная покатушка», Вс 10:00 «Спина, грудь и плечи — суперсеты» + 18:00 «Пресс».

тренировка (время + название) идёт сейчас (контур) линия текущего времени без времени старые данные 19 сегодня (glow-круг) 21 открытая дата (обводка) капсула периода подсветка окна — во всех сеточных видах

1 · Пикер вида — нижний лист кнопка в шапке подэкрана · тёмная тема

Точка входа — кнопка-«тюнеры» в шапке подэкрана (перед шестерёнкой; заголовок «GymHelper · Календарь» и ⚙ не меняются — e2e-локаторы целы). Тап → нижний лист «Вид календаря» по образцу скриншотов владельца: 5 пунктов (День / 3 дня / Неделя / Месяц / Год), у текущего — янтарная иконка и точка-отметка; тап по пункту — переключение вида с сохранением выбранной даты, тап по фону — закрыть. Крестика нет (дубль действий). Дефолтный вид — «Неделя» (решение владельца 19.11): применяется, пока в localStorage нет ключа gymCalView — и у обновившихся, и у новых пользователей. Фон листа — работающая неделя (тёмная тема для сравнения; остальные экраны макета — светлые).

2 · Неделя — 7 колонок на часовой шкале движок, 7 колонок · высота часа 44px · светлая

Полоса дней Пн–Вс: сегодня (Чт 19) — glow-круг, стрелки ‹ › листают неделями, заголовок «16–22 ноября». Тап по дню полосы — прыжок к этому дню. Сетка: гуттер с часами, колонки ≈41px, блок — время старта + название (до 3 строк, ellipsis), пересечение в Сб — две дорожки-полосы без текста (узко), тап → карточка. Капсула-подсветка периода — на всей полосе дней (окно недели = все 7 ячеек; во всех сеточных видах — решение владельца 19.11). Вт 17 — капсула «Жим лёжа» в полосе «без времени» (старые данные без started). Линия «сейчас» (19:47) — неделя содержит сегодня. Пилюли «Сегодня» нет — неделя текущая. Окно сетки 560px — в макете завышено для демонстрации всей недели; в проде ≈440–480px (≈10 часов в кадре, вечер — ниже по скроллу). Автоскролл при открытии — к активной тренировке −30 мин.

3 · День — одна колонка + пилюля «Сегодня» движок, 1 колонка · высота часа 56px · светлая

Суббота 21 ноября: колонка одна на всю ширину — блоки просторные (диапазон времени + название полностью). Пересечение в одном дне: Кроссфит 11:00–12:30 ∩ Велосипед 12:00–13:15 — колонка делится на две дорожки ≈150px, обе с текстом (в отличие от узких полос недели). Капсула-подсветка — на ячейке выбранного дня (СБ 21), обводка-якорь остаётся поверх (капсула на полосе дней — во всех сеточных видах, решение владельца 19.11). Плавающая пилюля «Сегодня» внизу по центру — видна, потому что открытый день ≠ сегодня; тап — возврат к сегодняшнему дню (Чт 19, там активная «Спина + бицепс» контуром и линия «сейчас» — видно на экране «3 дня»). Полоса дней: открытый день (СБ 21) — обводка-круг, сегодня — glow-круг; тап по любому дню полосы — переход к нему. Высота часа 56px — блок 1ч = 56px, дышит.

5 · Год — 12 мини-месяцев, весь год в кадре новый вид · сетка 3×4 · светлая

Сетка 3×4 — все 12 месяцев на одном экране (как в Outlook), без скролла. В мини-месяце: заголовок + буквенный ряд Пн–Вс + числа 8px; день с тренировкой — янтарная точка 3px под числом (несколько тренировок в день — одна точка, подробности в месячном виде); сегодня (19 ноября) — янтарная цифра. Навигация: ‹ › листают годами, заголовок «2026». Тап по мини-месяцу → месячный вид этого месяца (отдельные дни в годовом виде не тапуются — тап-зона ячейки ≈14px слишком мала; см. §9 спеки). Пилюли «Сегодня» нет — год текущий; в другом году — плавающая пилюля.
