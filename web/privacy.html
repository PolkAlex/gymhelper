Политика конфиденциальности

Дата последнего обновления: 08.11.2026

Оператор данных

Оператор персональных данных — владелец бота GymHelper (@GymPolkhovichBot). Используя бота и мини-приложение, ты соглашаешься с этой политикой.

Какие данные собираются

  • данные профиля: год и месяц рождения (для расчёта возраста и калорий), рост, вес, пол;
  • имя из Telegram (для отображения в интерфейсе);
  • история тренировок: упражнения, веса, подходы, повторения и время занятий.

Где хранятся данные

Данные хранятся на сервере оператора (VPS) в виде отдельного файла для каждого пользователя. Создаются резервные копии: до 20 последних версий на сервере и копии на устройстве оператора в течение 14 дней.

Как долго хранятся

Пока пользователь активен. Если ты не пользуешься ботом, данные остаются сохранёнными, чтобы при возвращении дневник был на месте.

Удаление данных

Удалить свои данные можно в любой момент командой /delete_my_data в боте. Для защиты от случайного нажатия бот просит подтвердить действие повторной командой /delete_my_data_confirm в течение 5 минут. После подтверждения файл с твоими данными удаляется безвозвратно; копии в резервных хранилищах удаляются автоматически по истечении срока их хранения.

Кто имеет доступ

Только оператор. Данные не передаются третьим лицам и не используются для рекламы.

Контакты

Вопросы по обработке данных — просто напиши боту.
