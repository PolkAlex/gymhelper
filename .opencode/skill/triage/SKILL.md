# Триаж сессии (порядок при старте)

1) **Заявки с телефона** (label `inbox` = мандат на работу без отдельного
   подтверждения владельца):

   ```powershell
   gh issue list --label inbox
   ```

   Есть заявки → оформить тикеты (тип/направление/приоритет/спринт — скилл
   `new-ticket`, правила AGENTS.md) и брать в работу по приоритетам; техничку и
   низкоприоритетное — по обычным правилам.

2) **Новые комментарии владельца** во ВСЕХ открытых issue/PR (не пропустить фидбек):

   ```powershell
   gh issue list --state open
   gh pr list --state open
   ```

   Свежие issue/PR просмотреть с комментариями; ответ на комментарий — комментарием
   в тот же issue/PR.

3) **CI**:

   ```powershell
   gh run list --limit 5
   ```

   Красный ран на main — выяснить причину и чинить в первую очередь.

4) **Доска** — аудит порядка:

   ```powershell
   node tools/board-audit.mjs
   ```

   Blocker'ы (пустые поля, спринты конвейера, борд↔issue, семьи) — чинить сразу;
   warnings — по ситуации. Правила — «Гигиена доски и тикетов» в AGENTS.md.
   Дополнительно глазами: тикеты в In Dev / Code Review / In Test без движения —
   что с ними.

5) **TODO.md** — свежие заметки владельца (читать в начале любой задачи).

6) **Счётчик багов владельца** — актуальное значение в AGENTS.md (п.9). Владелец
   принёс баг из работы агентов → +1; достигли 3/3 → владелец проводит полную
   перепроверку, затем счётчик сбрасывается.
