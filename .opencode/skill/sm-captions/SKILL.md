# SMM Captions — подписи и хештеги

Вход: тема/сценарий/черновик/скриншот поста. Выход: готовая подпись для копипаста + хештеги.
Без вопросов и меню — анализ и результат сразу.

## Воркфлоу

1. **Анализ входа** (2–3 строки): тема → ниша → ключевая мысль. Для черновика конкурента —
   разобрать их подход и сделать лучше.
2. **Подпись** по правилам платформы (ниже). Один явный CTA. Вопрос в конце.
3. **5 хештегов** по правилу 2+2+1.
4. Самопроверка по чеклисту + прогон через avoid-ai-writing перед выдачей.

## Правила подписи

### Instagram Reels (основной формат)
- 80–200 знаков на «короткую» версию; полный вариант для поста — до 900 знаков
- Хук в первых 125 знаках (до «ещё»): конфликт, трансформация, любопытство, цифра
- Ключевая фраза (1ПМ, дневник тренировок) — в первых 2 предложениях (SEO)
- CTA: шеры в директ («отправь тому, кто...») или сохранения («сохрани, чтобы не потерять») —
  в 10 раз ценнее лайков; RU-аудитория сохраняет активнее всех
- Хештеги 3–5 в самой подписи; без #fyp #viral #reels #instagood #подпишись
- Нет engagement bait («лайк если согласен», «отметь 3 друзей»), нет эмодзи в первой строке

### Telegram-канал
- 200–500 знаков, первый абзац виден целиком в превью
- Один вопрос в конце поста — комментарии главный сигнал
- Кнопка-ссылка на бота: `https://t.me/MyHelperGymBot?start=tg`

### Общие запреты
- Обещания результата («похудеешь за неделю», «гарантированный рост») — только факты
- Канцелярит, «уникальный/инновационный», третье лицо про продукт (см. avoid-ai-writing и В3)

## Хештеги: правило 2+2+1

| Слот | Что это | Примеры |
|---|---|---|
| 2 широких фитнес RU | большие охватные | #фитнес #тренировки |
| 2 узких «дневник» | целевая ниша | #дневниктренировок #тренировкадома |
| 1 нишевый под тему поста | тема конкретного поста | #1ПМ #жимлежа #приседания |

- Набор не повторять от поста к посту — состав под каждую тему свой (алгоритм ловит копипаст-наборы)
- Без гео-тегов (аудитория RU+BY, смешение лишнее)
- Ресёрч подсказок: MCP `free-seo` → `suggest` (Google autocomplete, hl=ru) и `trends_related`

## Формулы подписей (чередовать, не повторять одну)

Для охвата: «Миф: X. Факт: Y» / «[Цифра] → [результат] за [срок]» / «[A] vs [B]: что работает?»
Для вовлечения: «Ты [A] или [B]? И почему?» / «Непопулярное мнение: [тезис]. Согласен?»
Для продукта: «Мучаешься с [боль]? [Фича бота] — один раз настроил и забыл»
Для сохранений: «Сохрани: [структура/схема/памятка]»
