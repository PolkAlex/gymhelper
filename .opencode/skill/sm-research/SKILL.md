# SMM Research — тренды и конкуренты

Выход — бриф с доказательствами: ссылки, метрики, даты. Не «это в тренде», а
«3 поста с метриками, общий паттерн, какой угол взять нам».

## Важное ограничение

Оригинальные скиллы ScrapeCreators требуют `SCRAPECREATORS_API_KEY` (платный,
квоты не проверены — по решению владельца НЕ подключён). Доступные пути сейчас:

- MCP **free-seo**: `suggest`, `expand_questions`, `trends_related`, `trends_by_region`,
  `estimate_volumes`, `reddit_search` — спрос и формулировки аудитории (Google/Trends/Reddit).
- MCP **yt-transcript** / **video-analyzer**: транскрипт и метаданные YouTube-роликов
  конкурентов (что сработало: хук, структура, CTA).
- MCP **playwright**: живой просмотр публичных страниц (аккаунты, хештеги) — осторожно,
  только публичное, без логина.
- `websearch`/`webfetch` — подбор статей и подборок.
- Ручной путь владельца: листать Reels/профили руками и кидать ссылки агенту на разбор.

Instagram/TikTok без API ключа недоступны для автоматического сбора метрик — анализ
по ссылкам, которые владелец принёс вручную.

## Воркфлоу А. Тренды ниши

1. Зафиксировать: ниша (фитнес/дневник тренировок), регион (RU+BY, без гео-тегов в
   контенте), платформа (Instagram Reels приоритет), горизонт (неделя).
2. Собрать сигналы из 2–4 источников (free-seo подсказки/тренды; YouTube-шортсы конкурентов
   через yt-transcript; подборки статей через websearch).
3. Нормализовать: ссылка, автор, метрика (просмотры/лайки), дата, тема, формат, хук.
4. Кластеризовать по теме/формату/хуку/проблеме аудитории.
5. Ранжировать по силе доказательств (паттерн повторяется ≥3 раза у разных авторов),
   не по сырым просмотрам.
6. Перевести каждый тренд в идею для GymHelper (что именно снять/написать нам).

## Воркфлоу Б. Разбор конкурента

1. Вход: 1–3 профиля/канала (ссылки от владельца или найденные публично).
2. Снапшот: размер аудитории, позиционирование в био, частота постов.
3. Контент за сопоставимое окно: темы, форматы, хуки, CTA (метрики — что видно публично;
   точные числа без API не собирать, не выдумывать).
4. Аутлайеры: что у конкурента выбивается из его же медианы (по видимым метрикам).
5. Паттерны: рили контента, форматы, стиль хуков, механики CTA.
6. Пробелы: темы, которых избегают; вопросы аудитории без ответов; форматы, которые
   перформят, но никто в нише не использует.

## Формат брифа

```markdown
# SMM-бриф: {тема/конкурент}
## Главное
- Самая большая возможность:
- Что тестировать первым:
## Доказательства
| Тренд/паттерн | Источник(ссылки) | Почему сработал | Идея для GymHelper |
## Идеи контента (3–5)
1. ...
## Оговорки
- Только публичные данные; [дата сбора]
- [что не удалось посмотреть без API-ключа]
```

## Грабли

- Один залетевший пост ≠ тренд. Нужен повтор у разных авторов.
- Не сравнивать большие и маленькие аккаунты по сырым просмотрам.
- Чужой контент — источник идей, не материал для копирования: переписывать своими словами,
  проходить avoid-ai-writing.
- Не тянуть чужие цифры в наши посты без проверяемого источника (правило ig-carousel).
