[FIT-I1] Прозрачный расчёт калорий — MET по типу упражнения

Спека: docs/spec-fit-s1-calories.md. Источники стиля 1-в-1: web/style.css (Amber Glass, 2 темы). Суть фичи: поле met из каталога (243 записи, уже в проде) подключается к калькулятору, минуты — из времени каждого упражнения; экран «Как считаются калории» и разбор по упражнениям. Все числа на макете — реальный пример расчёта: вес 78 кг, присед 6.0 MET × 15 мин ≈ 123 ккал и т.д. Итого ≈ 255 ккал (по текущей формуле было бы ≈ 310).

A · Разбор ккал в карточке тренировки 390 · тёмная

Вход: История → карточка завершённой тренировки. Разворот «🔥 Ккал по упражнениям» заменяет черновик «(в разработке)» (app.js:1676): строки — MET из каталога + реальные минуты упражнения, итог — сумма. В разбор попадают только упражнения с записями. «Своё» без типа показывается бейджем «3.3 MET · тип не задан» (в этом примере все упражнения из каталога — случай показан на экранах C/D). Ссылка «Почему так?» ведёт на экран B.

C · «Своё упражнение»: выбор типа — влияет на MET 390 · тёмная

Новое состояние модалки добавления «Своего» (app.js:3032). Под полем названия — чипы типа; подсказка показывает, каким MET посчитается упражнение, и меняется при выборе. Почему так?

По текущей формуле (кг/мин на всю тренировку) этот же день дал бы ≈ 310 ккал — минуты пауз засчитаны, типы не учтены. «Своё» без типа — бейдж «3.3 MET · тип не задан», тап по нему открывает выбор типа (спека §5.4, §7).
