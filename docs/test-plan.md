### Бот-часть спринта 1 вне e2e (осознанный порог)

`/rest` (троттлинг 5 с/1 с), inline-отсчёт RestSession (editMessageText, «message is not
modified»), тихий пуш `disable_notification`, заморозка по 5-минутному молчанию, `/export`
(multipart sendDocument, анти-инъекция CSV) — **e2e не тестируются**: это длинные циклы с
внешними вызовами Telegram API. Чистая математика и формат данных покрыты юнит-уровнем
(`GymContractTest`, см. выше). Поведенческая часть проверена пробами кодера локально
(вне CI) и **требует ручной проверки владельцем на тестовом боте** перед деплоем
(чек-лист: лог подхода → отсчёт редактируется; +30/Стоп; финальный тихий пуш; `/rest 180`;
`/export` открывается в Excel; сохранение в шаблоны после завершения и из истории;
старт из шаблона и «повторить прошлую»).
