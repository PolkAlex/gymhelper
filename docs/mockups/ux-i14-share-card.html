[UX-I14] Виральный шеринг карточки тренировки

Кнопка «Поделиться» на завершённой тренировке → канва-картинка в стиле Amber Glass → системный шеринг Telegram → картинка с ссылкой t.me/MyHelperGymBot/app уезжает в любой чат. Спека: docs/spec-ux-i14-share-card.md.

жим штанги лёжа 120 кг × 3×8 → рекорд по реальному весу: 120 кг (владелец 19.11: «не по e1RM, а тот вес, который жал») · оценка 1ПМ по Эпли ≈ 152 кг — второстепенной строкой

объём 2880 + 1200 + 1260 = 5 340 кг · ⏱ 74 мин (1:14) · 🔥 MET 6.0 → 622 ккал · 🏋 9 подходов · 🔥 серия 12 тренировок подряд

A · Концепт «Amber Glass» — тёмный стеклянный базовая рекомендацияданные · 5 340 кг · рекорд 120 кг

Узнаваемо «наш»: тёмный фон с янтарными засветками, стеклянные карточки, свечение рекорда, пилюля-ссылка. Агрегаты — три отдельные стеклянные карточки (решение владельца 19.11 — было: слепленная полоса). В плашке рекорда — реальный вес подхода 120 кг, Эпли — мелко вторым планом. Канва 720×1280 (9:16), показ в масштабе ≈ 0.54. Рендер в проде — 1080×1920 (1.5×).

C · Концепт «Рекорд-постер» герой = рекорд

Эмоциональный максимум для тренировки с рекордом. Решение владельца 19.11: герой-число — реальный вес подхода (120 кг — «тот вес, который жал»), НЕ расчётный 1ПМ; Эпли — мелкой второй строкой. Именно здесь раньше стояли 152 кг по Эпли — заменено. Рекомендация спеки: если принят концепт A, этот режим наследуется внутрь A как «герой-слот = реальный вес» — отдельный дизайн не нужен.

ПараметрРешение
Агрегатытри отдельные стеклянные карточки в ряд: значение крупно, подпись ПОД значением (решение владельца 19.11 — полоса-стрип слеплялась)
Рекордгерой = реальный вес подхода («120 кг — который жал»), Эпли ≈ 152 — второстепенной строкой (решение владельца 19.11)
Формат v11080×1920 (9:16), PNG; 1080×1350 (4:5) — v2 той же функцией рендера
Темавсегда тёмная (бренд), независимо от темы приложения
Генерацияclient-side canvas в Mini App, без новых зависимостей; сервер не участвует
Шерингnavigator.share с файлом → шторка Telegram; fallback — скачивание PNG + тост
Ссылкаt.me/MyHelperGymBot/app (deep-link в Mini App); gym-helper.com — только статьи, на карточке нет
Приватностьбез имён, времени суток, веса тела, кастомного названия; EXIF/гео отсутствуют по природе canvas
МетрикаshareClick / shareOk / shareDownload в /stats (воронка виральности)
Ботне меняется (v1 — только Mini App)

Числа примера считаются функциями карточки приложения (workoutVolume, max вес подхода, calcWorkoutKcal, monthStreak) — расхождение «приложение vs картинка» исключено. Все три варианта и оба edge-состояния проверены на переполнение при 3 упражнениях: контент умещается в канву 9:16 с запасом (≈610–680px из 693px), агрегаты в 3 карточки по ≈105px ширины — подписи «время / ккал / подходов» не переносятся.
