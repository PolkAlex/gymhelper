Тема: расчёт одноповторного максимума (1ПМ) за 30 секунд. Продукт: GymHelper —
Telegram-бот, дневник тренировок. Дата: 25.11.2026.

## Как воспроизвести

### Карусель (HTML → PNG)

```powershell
# из корня репо; playwright — dev-зависимость e2e, уже в node_modules
node docs\marketing\samples\2026-11-25-1pm\render-carousel.js
```

Скрипт читает `carousel.html` рядом с собой, делает скриншот каждого `.slide`
(1080×1350) и предупреждает, если контент слайда вылезает за холст.
Правки текста — в `carousel.html`, затем перезапуск команды.

### Картинка-обложка (опционально, через MCP)

В сессии OpenCode (MCP `pollinations`):

```
Сгенерируй картинку 512×512: «minimal dark gym log icon, dumbbell with neon green
accent, flat vector style», outputPath = docs/marketing/samples
```

⚠️ MCPollinations называет файл `.png`, но Pollinations отдаёт JPEG — переименовать
в `.jpg` после сохранения.

### Транскрипт чужого видео (MCP `yt-transcript`)

```
tools["yt-transcript"].get_transcript({ url: "<YouTube URL или ID>", lang: "ru" })
```

## Самопроверка по скиллу avoid-ai-writing (1 проход + точечная правка)

- Найдено и исправлено: обложка карусели — корявая фраза «прогресс стоит не из-за
  дисциплины» → переписана («Программа без максимума — не план, а угадывание…»).
- P0/P1 находок в подписи и сценарии нет: нет канцелярита, «уникального/инновационного»,
  обещаний результата, engagement bait; зачин — прямой факт, не «в современном мире».
- Осознанные остатки (не правились): дефиниционные тире — обязательны русской
  типографикой; перечисление «254 упражнения, календарь, таймер отдыха» — факты
  продукта, не искусственное правило трёх.
- Аудит ручной (model-only): механический детектор оригинального скилла английский,
  на RU-текстах не запускался.

## Соответствие правилам канала

- Подпись ≤900 знаков, вопрос в конце ✓
- Хештеги 2+2+1: #фитнес #тренировки (широкие) / #дневниктренировок
  #программатренировок (узкие) / #1ПМ (нишевый), набор без гео ✓
- Продукт упоминается один раз в конце ролика, третье лицо ✓
- CTA без прямой ссылки («ссылка в шапке») ✓
- Публикация — вручную владельцем (автопостинг запрещён)
