## 1. Цель и пользовательская проблема

Сейчас настройки приложения размазаны по вкладке «Профиль» вперемешку с личными данными:
тема, таймер отдыха, полноэкранный режим, фон и «Персональный тренер» лежат рядом с
полом, возрастом и весом. Верхняя иконка профиля дублирует точку входа (ведёт на ту же
вкладку «Профиль», которая и так есть в нижней навигации).

**Решение**: верхняя иконка в топбаре становится шестерёнкой «Настройки» и открывает
отдельный подэкран «Настройки» (доступен с любой вкладки). Профиль остаётся вкладкой
нижней навигации и хранит только данные пользователя.

## 3. Навигация: вход и выход

### Точка входа
- Кнопка шестерёнки в `.topbar` (стиль нынешней `.tb-user`: 32×32, radius 9px, `background: var(--btn)`, `color: var(--muted)`, svg 18×18) — **одна на все вкладки** (История, Статистика, Техника, Профиль, а также Тренер и открытая карточка тренировки).
- `data-act="openSettings"`, `title="Настройки"`, `aria-label="Настройки"`.

### Экран
- Настройки — **подэкран-оверлей**, не вкладка нижней навигации. Нижняя навигация (4 таба + FAB) остаётся видимой; тап по любому табу закрывает Настройки и переходит на вкладку.
- Технически (предложение кодеру): флаг `settingsOpen` в state; `switchTab` сбрасывает его. Альтернатива — псевдовкладка `tab='settings'` вне `navHtml` — допустима, но флаг проще: сохраняется контекст открытой карточки тренировки (`viewWid`).
- Скролл при открытии — в 0 (согласовать с текущим поведением `openHistory`).

### Точка выхода
- Кнопка «←» слева в топбаре (та же геометрия 32×32, `ICONS.back`, `data-act="closeSettings"`) — возвращает на ту вкладку, с которой открыли Настройки.
- Заголовок топбара на экране: `Настройки`. Справа на экране Настроек кнопок нет.

### Заголовки вкладок (`names` в topbarHtml)
- `profile` снова подписывается **«Профиль»** (сейчас там артефакт «Настройки»).
- Для экрана Настроек титул отдельный (см. выше).

## 4. Тогл-компонент `.switch` (единый, переиспользуемый)

В дизайн-системе тогла НЕТ (сейчас: пара кнопок `.themetoggle`, псевдотогл `.toggle2`,
кнопка-действие fullscreen). Вводим **один** компонент для всех переключателей:
тема, полноэкранный режим, звук таймера. Компонент заменяет `.toggle2` (после миграции
звука `.toggle2`/`.themetoggle` из CSS удаляются).

### Геометрия и размеры
```
.switch            — кнопка-обёртка: 66×44 (тап-таргет ≥44px), фон прозрачный
  .sw-track        — трек 56×32, border-radius 999px, border 1px
  .sw-knob         — ручка ⌀26, absolute top/left 2px; travel = 56 − 26 − 4 = 24px (translateX)
  .sw-ico.l / .r   — «призрачная» иконка 14×14 на свободном конце трека (только у темы)
  svg внутри knob  — 15×15 (только у темы)
```

### CSS (добавка к `web/style.css`; значения поверх существующих токенов)
```css
/* [UX-S4] тогл-компонент: тема / полноэкранный / звук */
.switch {
    width: 66px; height: 44px; padding: 0; border: none; background: none;
    display: inline-flex; align-items: center; justify-content: flex-end;
    cursor: pointer; flex: none; font-family: inherit;
    -webkit-tap-highlight-color: transparent; touch-action: manipulation;
}
.sw-track {
    position: relative; width: 56px; height: 32px; border-radius: 999px;
    box-sizing: border-box;
    background: var(--sw-track-off); border: 1px solid var(--sw-track-brd);
    transition: background .2s ease, border-color .2s ease;
}
.switch.on .sw-track {
    background: linear-gradient(135deg, var(--accent-deep), var(--accent));
    border-color: transparent;
}
.sw-knob {
    position: absolute; top: 2px; left: 2px; width: 26px; height: 26px;
    border-radius: 50%; background: var(--sw-knob);
    border: 1px solid var(--sw-knob-brd);
    box-shadow: 0 2px 8px var(--card-shadow), inset 0 1px 0 var(--blik);
    display: flex; align-items: center; justify-content: center;
    color: var(--sw-knob-ico);
    transition: transform .22s cubic-bezier(.2,.8,.25,1), background .2s ease;
}
.switch.on .sw-knob {
    transform: translateX(24px);
    background: #fff; /* одинаковый в обеих темах: читается на янтарном треке */
    border-color: transparent;
    color: var(--accent-deep);
}
.sw-knob svg { width: 15px; height: 15px; pointer-events: none; }
.sw-ico { position: absolute; top: 50%; transform: translateY(-50%); width: 14px; height: 14px; color: var(--muted); opacity: .55; pointer-events: none; }
.sw-ico.l { left: 6px; } .sw-ico.r { right: 6px; }
.sw-ico svg { width: 14px; height: 14px; display: block; }
.switch.on .sw-ico { color: rgba(20,18,10,.45); opacity: 1; } /* призрак на янтарном */
.switch.locked { opacity: .45; pointer-events: none; }        /* disabled */
.switch:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; border-radius: 12px; }
/* переменные компонента (тёмная по умолчанию) */
:root, [data-theme="dark"] {
    --sw-track-off: rgba(0,0,0,.35);
    --sw-track-brd: rgba(255,255,255,.10);
    --sw-knob: rgba(255,255,255,.92);
    --sw-knob-brd: rgba(255,255,255,.25);
    --sw-knob-ico: #565b64;   /* иконка на белой ручке в OFF */
}
[data-theme="light"] {
    --sw-track-off: rgba(22,24,27,.14);
    --sw-track-brd: rgba(22,24,27,.10);
    --sw-knob: #ffffff;
    --sw-knob-brd: rgba(22,24,27,.12);
    --sw-knob-ico: #8a9099;
}
```
Также дополнить список `cursor: pointer` в конце style.css селектором `.switch`.

### Состояния
| Состояние | Класс / атрибут | Вид |
|---|---|---|
| OFF | без `.on`, `aria-checked="false"` | трек `--sw-track-off`, ручка слева (белая), иконка ручки серая |
| ON | `.on`, `aria-checked="true"` | трек — янтарный градиент (как `.seg-btn.on` / CTA), ручка справа белая, иконка `--accent-deep` |
| Disabled («locked») | `.locked`, `aria-disabled="true"` | полупрозрачный, клики отключены (`pointer-events:none`) |
| Focus | `:focus-visible` | янтарный контур |

Анимация: ручка переезжает за 0.22s (`cubic-bezier(.2,.8,.25,1)` — как модалка `mslide`); трек и фон ручки — 0.2s. Тема применяется мгновенно (без перехода всего документа — как сейчас).

### Доступность
- `role="switch"`, `aria-checked="true/false"`, `aria-label` («Тёмная тема», «Полноэкранный режим», «Звук по окончании»).
- Disabled: `aria-disabled="true"` + `pointer-events:none` (подпись под строкой объясняет причину).

### Иконки
- Тема: ручка несёт иконку **активной** темы; на свободном конце трека — «призрак» пассивной.
  Используются **существующие** `ICONS.sun` и `ICONS.moon` (новые не рисуем).
  - ON (тёмная): ручка справа — `moon`; призрак слева — `sun`.
  - OFF (светлая): ручка слева — `sun`; призрак справа — `moon`.
- Полноэкранный и звук — без иконок (только ручка). Иконки в разметку не включаются.

### Семантика подписей
Подпись строки формулируется так, чтобы ON/OFF читались честно:
- «**Тёмная тема**» (ON = тёмная тема) — не «Тема»: у нейтрального названия нет ON-состояния.
- «**Полноэкранный режим**» (ON = включён).
- «**Звук по окончании**» (ON = звук включён).

### Разметка строки настройки (паттерн `.setrow`)
```html
<div class="setrow">
  <span class="lbl">Тёмная тема</span>
  <button class="switch on" role="switch" aria-checked="true" aria-label="Тёмная тема">
    <span class="sw-track">
      <span class="sw-ico l">[ICONS.sun]</span>
      <span class="sw-knob">[ICONS.moon]</span>
    </span>
  </button>
</div>
```
`.setrow` уже есть в системе (label слева, контрол справа) — переиспользуется без правок.

## 5. Иконка шестерёнки `ICONS.gear`

Стиль набора: `_s()` — viewBox 24, `fill:none`, `stroke:currentColor`, `stroke-width 1.7`,
концы/соединения скруглены. Шестерёнка — «линейная»: два концентрических круга (корпус +
втулка) и 8 зубцов-штрихов, примыкающих к корпусу (в отличие от `sun` с зазором — иначе
сольётся с солнцем).

```js
/* [UX-S4] шестерёнка «Настройки» в topbar: корпус + втулка + 8 зубцов */
gear: _s('<circle cx="12" cy="12" r="6.2"/><circle cx="12" cy="12" r="2.6"/>' +
    '<path d="M12 2.8v3.2M12 18v3.2M2.8 12h3.2M18 12h3.2"/>' +
    '<path d="M5.4 5.4l2.2 2.2M16.4 16.4l2.2 2.2M18.6 5.4l-2.2 2.2M7.6 16.4l-2.2 2.2"/>'),
```
Отрисовка 18×18 в кнопке топбара (макет: секция «Иконка», крупный образец 48px —
читаемость проверена).

## 7. Профиль после переработки (вкладка из нижней навигации)

Состав — ровно 4 карточки, обёртка `.prof` сохраняется:
1. **«Профиль»** (саммари): заголовок `Профиль` (без ⚙️-эмодзи), meta-строка `М · 34 лет · 178 см · 78,5 кг`, `BMR ≈ … ккал/сут (Mifflin-St Jeor)`; у новичка — `Нужен для расчёта калорий 🔥`. Без изменений по логике.

тренер (все — в Настройки, см. §2).

## 8. Edge-кейсы

### 8.1 Сохранение состояния тоглов
Все ключи уже существуют — форматы не меняются, миграции нет:
| Настройка | Хранилище | Ключ / поле |
|---|---|---|
| Тема | localStorage | `gymTheme` (`'dark'`/`'light'`; `savedTheme()` понимает и старые значения) |
| Полноэкранный | localStorage | `gymFullscreen` (`'1'`/`'0'`, дефолт `'0'`) |
| Звук таймера | localStorage | `gymRestSound` (`'on'`/`'off'`) |
| Длительность отдыха | сервер (GymData) | `restSec` (0 = выкл, дефолт 90) — общий с ботом |
| Фон | localStorage | `gymBg` |
Тогл темы показывает **фактическую** тему (`data-theme` документа), а не «факт выбора»:
пока пользователь не трогал тогл, тема берётся из клиента Telegram (`themeHint`) и тогл
отражает применённое значение; первый тап фиксирует выбор в `gymTheme`.

### 8.2 Полноэкранный на старом клиенте
- Условие disabled: `!(tg && tg.requestFullscreen)` — считается при каждом рендере (не кэшировать: клиент мог обновиться между сессиями).
- Вид: тогл `.locked`, meta `Недоступно: обнови Telegram до 8.0+`.
- Существующая логика `fullscreenToggle` (тост «Не поддерживается этим Telegram», флаг не ставится) остаётся страховкой — из locked-тогла вызов не доходит.
- Флаг состояния восстанавливается на старте (`init`), вход подтверждается событием
  `fullscreenChanged` — после него делать `render()`, чтобы тогл показал актуальное
  состояние (проверить, что подписка уже перерисовывает UI; если нет — добавить).

### 8.3 Мгновенное применение темы
Тап по тоглу → `setTheme()` → `applyTheme()` меняет `data-theme` немедленно + `render()`.
Без анимаций перехода всего документа (как сейчас). Тогл в макете рендерится уже в
целевом состоянии.

### 8.4 Доступность с любой вкладки
Шестерёнка одна в топбаре — рисуется на всех состояниях, включая вкладку «Тренер» и
открытую карточку тренировки (топбар общий). Настройки поверх карточки тренировки:
`viewWid` не сбрасывается, «←» возвращает на карточку; нижняя навигация при этом тоже
закрывает Настройки (автосейв-выход как сейчас). Restbar/таймер отдыха продолжают висеть
над Настройками (это обычный контент-экран, логика `restbar` не трогается).

### 8.5 Узкие экраны (320–360px)
`.setrow` — подпись сжимается, тогл фиксированный 66×44 справа; чипы переносятся
`flex-wrap`. Проверить на 320px (эталон — карточка пола `.sexrow`, которая уже влезает).

### 8.6 Пустые/крайние значения
- «Своё…» валидируется как сейчас (30–600 сек), поле появляется только в custom-режиме.
- «Выкл» (restSec=0) — чип `Выкл` в `.on`; тогл звука при выключенном таймере остаётся
  рабочим (настройка хранится, звук просто не звучит — поведение не менялось и сейчас).

## 9. Что НЕ делаем и почему

| Отсечено | Почему |
|---|---|
| Настройки пятой вкладкой в нижней навигации | Навигация перегружена (4 + FAB уже норм); вход с топбара покрывает все вкладки; нижняя навигация — для ежедневных сценариев |
| Перенос «Пол»/перс. данных в Настройки | Это данные пользователя, не настройки приложения; тикет прямо говорит «Профиль остаётся» |
| Поле «Имя» в Профиле | В `GymData` имени нет; хранить имя из Telegram — отдельная фича (предложение вынесено владельцу, §11) |
| Показ пункта «Политика конфиденциальности» disabled в проде | Мёртвый пункт провоцирует тапы; место зарезервировано дизайном и спекой, рендер — вместе с ONB-T2 |
| Рендер настроек через сервер (GymData) | Все настройки кроме `restSec` локальные по дизайну («Картинка хранится только на этом устройстве»); менять модель синхронизации — вне тикета |
| Анимация «перелёта» при смене темы | Мгновенная смена — текущее поведение, проще и надёжнее в webview |
| Отдельный тогл «Своё…» времени отдыха | Чип + поле ввода — существующий проверенный паттерн [UX-T13] |
| Удаление `.toggle2` из кода в этом же тикете (отдельной строкой) | Входит в чек-лист: после миграции звука селекторы `.toggle2`/`.themetoggle` удаляются из style.css (мёртвый CSS). Оставлено в объёме S4, т.к. без этого останется мусор |

## 12. E2E-кейсы (дополнение к `tests/e2e.spec.js`)

1. **Шестерёнка на всех вкладках**: переключить каждую из 4 вкладок → кнопка `[aria-label="Настройки"]` присутствует в топбаре; клик → заголовок `Настройки`, видны карточки «Оформление», «Таймер отдыха», «Персональный тренер».
2. **Выход**: с каждой из 4 вкладок открыть Настройки → тап `[aria-label="Назад"]` → вернулись на исходную вкладку (заголовок топбара соответствует).
3. **Тогл темы**: клик по `[role="switch"][aria-label="Тёмная тема"]` → `html[data-theme]` меняется мгновенно, `aria-checked` инвертируется, `localStorage.gymTheme` обновлён; повторный клик возвращает.
4. **Тогл fullscreen (Telegram 8.0+ мок)**: клик → `localStorage.gymFullscreen === '1'`, тогл ON; клик → `'0'`, OFF.
5. **Тогл fullscreen (старый клиент)**: мок без `tg.requestFullscreen` → тогл имеет `aria-disabled="true"`, meta-текст «Недоступно: обнови Telegram до 8.0+»; тап не меняет `gymFullscreen`.
6. **Таймер**: тап чипа `60` → активен, `G.restSec=60`; тап `Выкл` → `restSec=0`; `Своё…` → поле + `ОК` сохраняет значение; тогл «Звук по окончании» пишет `gymRestSound` on/off.
7. **Фон**: тап «Убрать фон» → класс `has-bg` снят, тост «Фон убран».
8. **Профиль переработан**: на вкладке Профиль НЕТ заголовков «Тема оформления», «Таймер отдыха», «Фон приложения», «Полноэкранный режим», «Персональный тренер»; карточки «Пол» и перс. данных работают (сохранение профиля не сломано).
9. **Тренер**: в Настройках тап «Открыть раздел» → вкладка coach (заголовок `Тренер`), Настройки закрыты.
10. **Политика**: пункта «Политика конфиденциальности» на экране нет (до ONB-T2).
11. **Карточка тренировки**: открыть тренировку → шестерёнка в топбаре доступна; выйти из Настроек → карточка тренировки восстановлена (`viewWid` сохранён).
