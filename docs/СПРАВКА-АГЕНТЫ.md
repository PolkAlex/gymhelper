# 📖 Справка: агенты в MyHelper

## Главное правило
Всё в **одном окне** opencode. Пишешь в чат — слушает **lead** (диспетчер), он сам зовёт остальных.
Изменения конфига/агентов вступают в силу только после перезапуска opencode (`/exit` → запустить заново).

## Режимы (переключение — Tab)
| Режим | Что делает |
|---|---|
| `lead` | Основная работа: ведёт задачу по цепочке агентов |
| `plan` | Обсуждение без правок кода (только читает) |
| `build` | Кодинг напрямую, без диспетчера |

## Роли
| Кого звать | За что отвечает |
|---|---|
| `@design` | Макеты и спецификации → `docs/`, `docs/mockups/*.html` (смотреть в браузере). Код не трогает |
| `@coder` | Пишет код: Java (`src/gym/`), JS (`web/`) |
| `@tester` | Тесты: e2e-сценарии-тапы, 4 устройства (desktop/iPhone/Pixel/Android-360), юнит-тесты Java, карта покрытия `docs/test-plan.md` |
| `@reviewer` | Проверка кода перед завершением (только читает) |

## Слэш-команды
- `/design <что>` — макет фичи
- `/test` — прогнать все тесты
- `/review` — ревью текущих изменений

## Примеры сообщений в чат
```
сделай экран «Питание» в приложении
@tester прогони все тесты
/design макет экрана профиля
план: как добавить экспорт тренировок?   ← сначала обсудить (режим plan)
```

## Тесты вручную (PowerShell, из корня)
```powershell
.\gradlew.bat --no-daemon build            # сборка + контрактный тест (Gradle)
.\gradlew.bat --no-daemon contractTest     # только контрактный тест
npx playwright test                        # все e2e (4 устройства, сервер сам поднимется)
npx playwright test --project=desktop      # быстрый прогон, только десктоп
npx playwright test --project=iphone13     # iPhone 13 (WebKit установлен)
node tests/check.js                        # быстрая статическая проверка
.\test.bat                                 # полный цикл для человека (в конце Enter)
```

## GitHub (gh CLI + доска задач)
```powershell
gh issue list                              # все задачи
gh issue view 3                            # подробности задачи №3
gh issue create --label feature --title "..." --body "..."
gh issue close 3 --comment "сделано тем-то"
```
- Доска (канбан): **https://github.com/users/PolkAlex/projects/1**
- Пайплайн колонок: Todo → In Design → In Dev → Code Review → In Test → Ready To Deploy → Done
- CI гоняется на каждый пуш: сборка + контрактный тест + e2e на 4 устройствах
- Статус: вкладка **Actions** в репозитории; бейдж — вверху README

## Docker (файлы готовы, VPS пока на systemd)
```powershell
# локально нужен Docker Desktop; на VPS — docker compose
# токен в файл .env: GYM_BOT_TOKEN=...
docker compose up -d --build
```

## Если что-то не так
- opencode не стартует: запусти с `OPENCODE_DISABLE_PROJECT_CONFIG=1`, исправь `opencode.json`
- Красный тест на одном устройстве, зелёный на другом — это баг вёрстки/логики, скажи lead

## Где что лежит
```
.opencode/agent/*.md      — агенты (lead, design, coder, tester, reviewer)
.opencode/command/*.md    — команды (/design, /test, /review)
AGENTS.md                 — правила проекта, читают все агенты
docs/test-plan.md         — карта покрытия тестами
docs/mockups/             — HTML-макеты экранов (дизайнер)
```
