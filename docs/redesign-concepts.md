# Redesign Mini App — 5 концептов визуального языка

Задача: [DSN-T1] (issue #24) · Story: [DSN-S1] (#23) · Epic: [DSN-E1] (#22) · Idea: [DSN-I1] (#8)

Макеты: `docs/mockups/concept-1.html` … `concept-5.html` (самодостаточные, открываются двойным кликом).
В каждом макете — 3 экрана: **История** (список + развёрнутая тренировка), **Новая запись** (форма),
**отличительный компонент** концепта. Все макеты отрисованы под ширину телефона 390px,
проверены на 360px и 430px (вёрстка резиновая, без горизонтального скролла).

---

## 1. Цель и пользовательская проблема

Текущий UI (10 soft-тем на CSS-переменных) функционален, но выглядит «плоским и устаревшим»
(формулировка владельца, issue #8). UX-логика обкатана — редизайн затрагивает визуальный язык
и может пересматривать навигацию (решение 4B), но не меняет структуру данных и сценарии.

Целевое ощущение: **тёмный фон + яркий акцент, крупные цифры, мягкие скругления, глубина
карточек / glassmorphism, нативность уровня Instagram / Telegram / Альфа-Банк BY**.

## 1.1. Сценарии использования макетов (шаги владельца)

1. Владелец открывает `docs/mockups/concept-1.html` … `concept-5.html` двойным кликом
   (браузер, без сборки — файлы самодостаточные).
2. В каждом файле три «телефона» друг под другом: История → Новая запись → компонент.
   В concept-5 тёмный и светлый клиент показаны как два отдельных телефона.
3. Форма «Новая запись» интерактивна: кнопки инкрементов, ряды значений и бейдж
   «Предыдущий подход: 65 кг» реально меняют поля — UX-I1 проверяется прямо в макете.
4. Владелец выбирает концепт (или просит гибрид: например «1, но FAB из 3») — дальше
   тираж на остальные экраны (решение 1B, issue #8).
5. Проверка отзывов на узких/широких телефонах уже сделана дизайнером: Playwright,
   вёрстка без переполнений на 360 / 390 / 430 px (все 5 файлов).

## 1.2. Состояния экранов (для будущего тиража, единые для всех концептов)

| Состояние | Поведение |
|---|---|
| Загрузка | Skeleton-плейсхолдеры карточек (3 шт.), без спиннеров; фон = фон темы |
| Пустая история | Иллюстрация-иконка + текст «Пока пусто. Начни первую тренировку!» + акцентная кнопка старта |
| Ошибка сети | Тост в стиле концепта («Не удалось загрузить, повтори ещё раз») + повторная попытка по тапу |
| Форма: пустой вес | Трактовка «0 — без веса» сохраняется (совместимость со старой логикой GymData); слова «макс» нет (решение #10) |
| Форма: невалидный ввод | Тост с подсказкой «Повторения: например 12, 8-10» — как согласовано в #10 |

## 2. Принципы, общие для всех концептов

| # | Принцип | Детали |
|---|---|---|
| G1 | Mobile-first 380–430px | Оптимизация под 390 (iPhone 12–17). Проверка на 360 и 430 обязательна. Никаких горизонтальных скроллов; ряды кнопок — flex с `min-width:0`, инкременты веса переживают 360px |
| G2 | Telegram themeParams | При старте читаем `Telegram.WebApp.themeParams` + `colorScheme`. Каждый концепт задаёт маппинг: какие свои переменные фиксированы (бренд), какие берутся из клиента (фон/текст/кнопка). См. таблицу в каждом концепте |
| G3 | Haptic feedback | `HapticFeedback.impactOccurred('light')` — тапы по кнопкам-цифрам и табам; `'medium'` — «Добавить»/CTA; `notificationOccurred('success')` — сохранение записи; `selectionChanged()` — переключение табов/тем |
| G4 | Безопасные зоны | `viewport-fit=cover`; контент под шапкой Telegram (UX-I2): шапка Telegram остаётся системной, наш контент начинается сразу под ней с мягким градиентом; нижняя навигация — `padding-bottom: env(safe-area-inset-bottom)` |
| G5 | Полноэкранный режим | `BotCommand`/`WebApp.expand()` + `content under header`: фон приложения совпадает с фоном шапки, стык невидим (UX-I2) |
| G6 | Цифровая типографика | `font-variant-numeric: tabular-nums`; 3 уровня цифр: hero (34–44px/800), карточная метрика (20–28px/700), служебная (12–13px/600) |
| G7 | Шкала скруглений | Единая шкала на концепт (например 10/14/18/26) — не более 4 значений |
| G8 | Тексты | Русские; **нет слова «макс»** (решения #9/#10); **нет чипсов-подсказок** в форме записи; подпись повторений — ровно «Повторения (например 12, 8-10)» |
| G9 | Тап-таргеты | Кнопки ≥ 44px высоты, отступ между целями ≥ 8px |
| G10 | Анимации | 150–250 ms, ease-out, только transform/opacity; `:active` scale 0.97–0.98 |
| G11 | Тёмная/светлая адаптация | У каждого концепта есть светлая и тёмная пара значений палитры (у концепта 5 адаптацию даёт сам Telegram) |

### Форма «Новая запись» — единый состав (решения владельца #9/#10)

Во всех 5 концептах форма идентична по составу, различается только стилем:

- Заголовок «Новая запись», подзаголовок — название упражнения;
- бейдж **UX-I1**: «Предыдущий подход: 65 кг» — пилюля рядом с полем веса, тап подставляет
  значение в один тап (в макетах кнопка рабочая);
- поле **Вес, кг** + ряд инкрементов `+0,5 · +1 · +2 · +5 · +10 · +15 · +20 · +50` +
  ряд значений `10 · 20 · 30 · 50 · 60 · 80 · 100 · 200`;
- поле **Подходы** + кнопки `1…8`;
- поле с подписью **«Повторения (например 12, 8-10)»** + кнопки `1…8` и инкременты `+1 · +2 · +5 · +10`;
- кнопка **«Добавить»** (широкая, акцентная);
- никаких чипсов «70/90/95/100 кг», «Без веса», «12/8/6-7/10»; слова «макс» нет нигде.

> Открытый вопрос владельцу: в текущем коде у повторений есть второй ряд `9 10 11 12`.
> Формулировка задачи («кнопки 1…8 и +1…+10») его не упоминает — в макетах оставлены
> только 1–8 и +1/+2/+5/+10. Если ряд 9–12 нужен — вернуть одним рядом.

## 3. Концепт 1 — «Mint Ledger» (тёмный finance, Stockline vibe)

Референсы: Stockline (референс владельца №1), текущая тема `stockline` в style.css.
Метафора: тренировка = инвестиция; недельный тоннаж = «портфель».

### Палитра (тёмная, основная)

| Роль | Hex |
|---|---|
| Фон | `#0E1116` |
| Карточка | `#171D25` |
| Карточка-2 (вложенные блоки) | `#202833` |
| Поле ввода | `#131922` |
| Текст | `#E9EEF4` |
| Приглушённый | `#8B98A8` |
| Акцент (мята) | `#3DDC97` |
| Акцент-градиент | `linear-gradient(135deg, #2BB37F, #3DDC97)` |
| Текст на акценте | `#0B1F16` |
| Рост (delta ↑) | `#3DDC97` · Падение (delta ↓) `#FF7A7A` |
| Границы | `#262F3A` |

Светлая пара: фон `#F4F6F8`, карточка `#FFFFFF`, текст `#1B222B`, акцент `#1FA971`, muted `#7A8794`.

### Типографика

- Пара: системная `SF Pro Display / Segoe UI Variable / Segoe UI / Roboto` (без внешних шрифтов).
- Hero-цифра тоннажа: 40px / 800 / tabular-nums.
- Заголовок экрана: 20px / 700. Название тренировки: 16px / 700.
- Метаданные, подписи полей: 13px / 400–500, muted.
- Кнопки-цифры: 13px / 600.

### Композиция и отличия

- Hero-карточка «Тоннаж недели» с градиентной заливкой мяты, крупной цифрой и дельтой
  `+12% ↑` — как карточка портфеля в Stockline.
- Sparkline (SVG, 64×24) на каждой карточке тренировки — тренд веса упражнения.
- Нижняя навигация: 4 таба + **центральная выпирающая круглая FAB «+»** (как в Stockline).
- Числовые дельты зелёным/красным — единственный концепт с биржевой семантикой цвета.
- Отличительный компонент: **финансовый hero + sparkline-тренд**.

- Отличительный компонент: **кольцо прогресса недели** (SVG-дуга, стеклянная карточка).

## 7. Концепт 5 — «TG Native» (авто-адаптация к теме клиента через themeParams)

Референс: сам Telegram (нативные Mini App: @wallet, @durger). Концепт без собственного
«окрашивания»: приложение выглядит родным в любом клиенте — тёмном, светлом, любом акценте.

### Маппинг themeParams → переменные

| Переменная приложения | Источник (themeParams) | Fallback (тёмный TG Desktop) |
|---|---|---|
| `--bg` | `bg_color` | `#17212B` |
| `--card` | `secondary_bg_color` | `#232E3C` |
| `--text` | `text_color` | `#EEF4F9` |
| `--muted` | `hint_color` | `#70808F` |
| `--accent` (кнопки) | `button_color` | `#5288C1` |
| `--on-accent` | `button_text_color` | `#FFFFFF` |
| `--link` (акцент цифр) | `link_color` | `#6AB3F3` |
| `--danger` | нет в themeParams | фиксированный `#E06C5F` |

Светлый fallback (если клиент светлый, themeParams придут светлые): тот же маппинг, ноль правок.

### Типографика

- Пара: системная (на Android в TG это Roboto, на iOS — SF — автоматически нативно).
- Размеры сдержанные: заголовок 18px/700, цифры карточек 22px/700, hero 32px/700.

### Композиция и отличия

- Радиусы 12/16, разделители 1px `rgba(128,140,155,0.15)` — сдержанная «телеграшина».
- Кнопки — цвет `button_color` клиента (у владельца могут быть любого цвета — это фича).
- Навигация: нижний таб-бар + круглая FAB в цвете `button_color`.
- Отличительный компонент: **график недели** (столбчатая диаграмма тоннажа по дням,
  стиль Telegram Statistics) + карточка максимума.
- В макете показаны обе темы: тёмный fallback и светлый клиент — рядом.

## 8. Что НЕ делаем и почему

| Отсечено | Причина |
|---|---|
| Чипсы-подсказки веса/повторений в новой форме | Прямое решение владельца (#9) — удалены |
| Слово «макс» в подписях/валидации | Прямое решение владельца (#10): подпись «Повторения (например 12, 8-10)» |
| Собственные темы, переключаемые пользователем (10 палитр) | На время редизайна: каждый концепт = 1 тёмная + 1 светлая пара; выбор темы пользователя — отдельное решение после выбора концепта. Концепт 5 вообще без своих тем |
| Веб-шрифты (Google Fonts и пр.) | Ограничение проекта: без внешних зависимостей; системные стеки дают нативность |
| burger-меню / боковой rail | На 360–430px нижняя навигация эргономичнее; rail остался в прошлом UI |
| Кастомный числовой keypad для веса | Нативная клавиатура Telegram + инкременты покрывают ввод; keypad — лишний хром |
| Перестройка структуры данных/сценариев | Задача про визуальный язык; UX-логика обкатана (issue #8) |
| Анимации > 300ms, parallax, Lottie | Без зависимостей; тяжёлые анимации мешают вводу |

## 9. Критерии выбора (для владельца)

1. **Mint Ledger** — если хочется «дорогого finance» и метрик вперёд (самый близкий к референсу Stockline).
2. **Amber Drive** — максимум энергии и контраста, самый «мужской/спортивный» характер.
3. **Deep Forest Glass** — преемственность текущему тону + glassmorphism, самый «атмосферный».
4. **Clean Split** — если после тёмных референсов захочется светлого и максимально нативного к iOS.
5. **TG Native** — если важна идеальная интеграция с клиентом Telegram и минимальная стоимость поддержки тем.

После выбора концепта (решение 1B) он тиражируется на все экраны: статистика, каталог,
профиль, тех-экран, тренер — отдельными задачами.

## 10. Выбранный гибрид — «Amber Glass» (статус: **ждёт утверждения владельцем**)

Макет: `docs/mockups/concept-hybrid.html`. Решение владельца по итогам выбора:
«нравится номер два, но стекло из номера 3, шрифты из номера 1, нижнее меню из номера 1.
Иконки из 2 не нравятся — исправим отдельным тикетом [UX-I3] (#25)».

### Что откуда взято

| Слой | Источник | Что именно |
|---|---|---|

### Форма «Новая запись» — финальные решения владельца (внесены в макет)

- Подпись поля веса: **«Вес, кг (0 — без веса)»** (пояснение возвращено);
- повторения: кнопки **1–8 + инкременты +1/+2/+5/+10**, ряда 9–12 нет;
- чипсов-подсказок нет, слова «макс» нет (решения #9/#10 сохраняются);
- бейдж UX-I1: «↺ Предыдущий подход: N кг — подставить» — подстановка в один тап;
- поля сгруппированы в стеклянные карточки, инкременты — залитый янтарь с тёмным текстом.
